# Anthropic

Anthropic 是开发 Claude 系列大模型的美国 AI 公司，也提供 Claude Code 这类编程工具。它限制中国用户、企业和疑似中转访问的做法，在 2026 年引发过争议，牵涉到反蒸馏检测和平台信任边界。脑总在 2026-10-22 的直播里也提到它想防止别人蒸馏模型。

更早，2026-04-19 讲新事物爆发时找卡位公司，他转述一位朋友举的 AI 编程的例子：能解决 AI 编程问题的公司里，现在最好的就是 Claude，也就是 Anthropic。他说「如果Anthropic今年上市，很有可能成为一波情绪的集中倾泻点」（这是有条件的说法；它当时有没有上市计划，图谱没有查），见 [[稀缺新股在概念最热时上市，先爆炒再杀泡沫]] 和 [[新事物爆发时，找卡在约束条件上的公司]]。
