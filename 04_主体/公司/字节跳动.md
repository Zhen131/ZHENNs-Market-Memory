# 字节跳动

字节跳动是靠推荐算法起家的中国互联网公司：先做新闻客户端今日头条，再做短视频抖音和它的海外版 TikTok。推荐算法本身就要大量算力，所以它在 AI 这一轮之前就已经是算力大户；它把这套能力对外卖，就是企业云服务平台火山引擎。公司没有上市。

## 关键事实

- **创办**：2012 年 3 月由张一鸣、梁汝波创办（维基百科，仅作参考）。
- **产品**：今日头条、抖音、TikTok；抖音约在 2016 年推出（只查到问答网站的说法，未核实）。
- **火山引擎**：字节跳动推出的企业云服务平台，归入北京火山引擎科技有限公司运营（凤凰网科技）。
- **和海外大模型**：据《金融时报》2026 年 7 月的报道，字节跳动给工程师报销 Anthropic 编程工具 Claude Code 的个人订阅，工程师用 VPN 登录，Anthropic 随后开始封堵这类通道，见 [[2026 - 美国 - Anthropic Claude Code 中国访问检测争议]]。

## 脑总怎么提到它

- 2026-05-16：讲独立 AIDC 为什么比房地产开发商还弱时，他说这门生意只有大厂做才有逻辑，因为大厂能用自家业务消化算力：「字节跳动在做 AI之前，火山引擎对算力的需求就已经相当可观」，就算 AI 投错了方向，存量业务也能把算力用掉（见 [[独立 AIDC 比房地产开发商还弱：借钱建、没预付、折旧快]]）。
- 2026-10-22：他把互联网公司比作矿业公司、用户注意力比作矿，说矿还在增长的只点了字节一家，TikTok 还能在海外扩张（见 [[互联网公司像矿业公司，注意力就是矿]]）。
