# 欧洲概览

这篇笔记不是欧洲通史，而是从第一次世界大战切入，记录欧洲的政治联盟、帝国结构、金融中心和跨境债务怎样彼此影响。战争前，欧洲既是全球工业与金融中心，也是一个由相互戒备的列强、刚性动员计划和殖民帝国组成的高风险系统；战争后，它又背上了公共债务、赔款、通胀和新边界留下的长期负担。

## 一战前的欧洲为什么既强大又脆弱

德意志、奥匈、俄国和奥斯曼等帝国，与法国、英国、塞尔维亚等国家处在联盟承诺、安全困境和民族主义压力之中。征兵制、铁路动员、军备竞赛和刚性作战计划提高了军事能力，也压缩了危机发生后的外交回旋时间。

金融上，伦敦是全球金融中心，[[金本位制]]、跨境银行与贸易信用支持资本和商品流动。德国、英国和法国拥有强大工业基础，却仍依赖原料、粮食、航运和海外融资。列强还能从殖民地取得兵员、税收、资源和战略纵深，这让欧洲拥有全球动员能力，也让发生在欧洲的战争迅速扩散到其他地区。

## 第一次世界大战如何改变欧洲

[[1914 - 全球 - 第一次世界大战]] 同时改变了欧洲的四张地图：

- 政治地图：多个帝国崩解，新国家与新边界出现，但民族与领土争议没有随停战消失。
- 财政地图：交战国积累巨额公共债务，胜利国也并非财务上的无损赢家。
- 货币地图：战前 [[金本位制]] 秩序被打断，通胀、汇率和战后恢复平价成为长期政治问题。
- 债权地图：美国对欧洲盟国的贷款、盟国间债务与德国赔款形成相互嵌套的支付链。

```text
总体战摧毁与军费
→ 欧洲政府债务与进口需求上升
→ 对美国信贷和物资依赖加深
→ 战后赔款与盟国债务相互牵连
→ 欧洲金融稳定依赖跨国协调和持续资本流动
```

## 这些变化怎样接回现有研究

[[1914 - 全球 - 第一次世界大战]]是一场由欧洲危机升级而成的全球总体战。[[战时财政与货币扩张]]解释政府如何动员税收、银行信用和社会资源；[[政府债券]]把战争支出延后为未来偿付责任；[[金本位制]]则说明战前货币承诺为什么在战争中受到冲击。货币、黄金和跨境债权的变化，需要在后续国家节点中继续拆开。

## 仍待补全的欧洲主线

- 后续应分别建立英国、德国、法国、俄国等国家节点，比较战争融资、通胀、社会承受力与战后调整。
- 第二次世界大战入库后，需要把 欧洲 节点扩展为两次世界大战之间的连续资产负债表故事。
- 一战后新边界、少数族群问题、赔款和外债如何与政治激进化互动，需要独立来源和比较笔记支持。
