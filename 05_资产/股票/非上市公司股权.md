# 非上市公司股权

[[非上市公司股权]] 可以代表创始人、员工或投资者对一家未上市公司的所有权，也可能来自期权行权或员工持股平台。它的价值来自公司未来现金流和可能的退出机会，却没有公开市场股票那样连续、透明的价格。

所以，融资新闻里的“估值”不是持有人随时可以拿走的现金。真正能实现多少价值，要看这是谁的权益、能不能转让、什么时候有买家，以及发生争议时合同能否执行。

## 为什么账面估值常常高于可实现价值

未上市公司的价格通常来自某轮融资、内部估值或少量二级交易，不代表所有股份都能按同一价格出售。创始人的控制权股份、投资者带优先权的股份和普通员工持有的权益，条款可能完全不同。

流动性是最直接的折价来源。公司章程、股东协议、优先购买权和锁定期都可能限制转让；公司披露较少，外部买方又会因信息不足要求更高折价。只有 [[首次公开募股（IPO）|IPO]]、并购或可靠的二级交易出现，账面价值才更接近可实现财富。

```text
公司经营与融资形成估值
→ 不同持有人取得不同权利的股份或期权
→ 信息不对称和转让限制压低可交易性
→ 上市、并购或二级交易提供退出
→ 扣除行权、税费和折价后才是可实现价值
```

## 员工持有的权益为什么更复杂

员工拿到的可能是 [[员工股票期权]]，而不是已经登记的股份。它先受 [[归属与行权条件]] 约束，行权后还要面对转让和流动性问题。即使公司整体估值上升，个人也可能因为离职窗口、授予主体或合同执行问题无法获得相同收益。

这说明 [[股权激励]] 同时是一种报酬安排和风险分配。公司用未来权益节省今天的现金，员工则承担公司失败、估值下修和退出迟延的风险。授予主体与实际经营主体分离时，还要检查 [[合同关系分离与责任套利]] 是否会增加追索成本。

## 上市前为什么会重新定价

上市把原来只在少数人之间讨论的估值和权利安排推向公开审查。员工激励池、早期投资者权利、潜在稀释和未解决纠纷，都可能进入 [[Pre-IPO 阶段治理风险]]。

市场会重新问：谁真正拥有股份，哪些权利已经归属，转让限制何时解除，上市主体是否承担相关义务。信息更充分可能降低不确定性，也可能暴露过去被高估或无法兑现的权益。

## 小红书材料说明了问题框架，而非事实结论

[[2026 - 中国 - 小红书 IPO 员工期权争议]] 的用户材料把员工期权的账面升值与实际兑现困难放在一起。争议细节尚未得到公开材料确认，因此不能判断员工实际持有什么，也不能计算可能损失。

要继续核验，至少需要合同或上市文件说明：权益属于境外主体、境内主体还是员工持股平台，如何归属和行权，离职后怎样处理，以及争议适用哪个司法辖区。不能从一个未核验故事外推 [[中国概览]] 中全部未上市公司。

## 这类资产应该怎样看

评估非上市公司股权，先把“公司值多少”和“我能拿到多少”分开。前者看经营与融资估值，后者还要扣除流动性、条款、税费和执行风险。

[[创始贡献者清退与 Pre-IPO 激励清理对比]] 提醒我们，成功会让分配冲突显性化；但任何具体权益是否成立，仍应回到正式文件。估值可以表达市场期待，只有清楚的权利和退出路径才能把期待变成资产。
