# 归属与行权条件

公司说“授予你一万份期权”，不等于员工当天就拥有一万份可以出售的股票。归属与行权条件决定的是：这项权利什么时候真正属于员工，员工又能在什么时间、以什么代价把它变成股份。

它们是 [[股权激励]] 合同里最容易被忽略、也最容易在离职和上市前引发争议的门槛。授予数量回答“可能有多少”，归属与行权回答“最终拿得到多少”。

## 归属、行权和变现是三件事

归属（vesting）通常要求员工工作满一定时间、达到业绩条件，或等到某个约定事件发生。未归属的部分往往会在离职时失效。

行权（exercise）是下一步。已经归属的 [[员工股票期权]] 通常仍要在有效期内支付行权价，才能变成股份或相应权益。合同还可能给离职员工设置很短的行权窗口，错过后即使已经归属也可能失效。

变现又是第三步。员工行权后得到 [[非上市公司股权]]，不代表马上有人愿意购买。只有 [[首次公开募股（IPO）|IPO]]、并购或二级交易等流动性事件出现，账面权益才更接近现金。禁售期发生在取得股份或上市交易之后，与决定权利是否成立的归属条件不同。

```text
公司授予权益
→ 时间、绩效或事件条件逐步满足
→ 权利归属
→ 员工在窗口内付出成本行权
→ 流动性事件提供出售机会
→ 账面权益才可能变成现金
```

## 为什么离职节点特别重要

离职可能同时影响未归属部分、已归属部分的行权窗口，以及公司对绩效和终止原因的认定。公司估值下跌时，员工还可能发现行权成本高于潜在收益；融资困难或上市延迟时，即使愿意行权，也可能长期无法变现。

因此，研究拟上市公司不能只看激励池有多大，还要看归属节奏、离职规则、行权期限和争议数量。若公司在上市前集中解除接近归属节点的员工关系，需要进一步核查它是正常组织调整，还是可能形成 [[Pre-IPO 阶段治理风险]]。如果授予主体与雇佣主体分离，执行问题还会连接 [[合同关系分离与责任套利]]。

## 小红书争议目前缺少哪些事实

[[2026 - 中国 - 小红书 IPO 员工期权争议]] 的用户材料把冲突描述为：员工接近或已经满足条件时，公司通过解约切断了兑现路径。这一说法尚无公开材料证实。

现在还不知道授予日期、归属安排、业绩条件、终止条款和行权窗口，也无法确认期权属于境内还是境外主体。若期权由境外主体授予，境内劳动程序能处理哪些请求，还要结合合同和司法管辖条款判断。以上都不能由口述替代。

## 看一份激励时应该算哪几层

员工权益的真实价值不能只用授予数量乘以公司估值。至少要逐层检查：权利是否已经归属、能否行权、行权后能否出售、发生争议时能否执行。

税务、外汇和股份转让限制也会改变最后到手的价值，尤其是在 [[中国]] 所涉及的跨境上市公司中。这里的框架可以帮助提问，但不能替代具体计划文件与专业法律意见。
