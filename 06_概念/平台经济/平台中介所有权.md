# 平台中介所有权

用户在商店里点击“购买”并支付全价，很容易感觉自己已经拥有了数字内容。但如果下载、验证、转让和长期访问都离不开平台账号与服务器，用户得到的更接近一项由平台持续中介的许可。

平台中介所有权要说明的，就是“付过钱”和“能够自由处置”之间的差别。判断用户到底拥有多少，不能只看购买按钮，还要看平台改规则、关闭商店或封禁账号以后，内容是否仍由用户控制。

## 实体介质与数字许可差在哪里

实体光盘或卡带通常可以保存、借用、转卖并离线使用。数字购买则常绑定特定账号，受许可条款、DRM、下载服务器和地区规则约束。订阅明确告诉用户是在租用，数字购买却更容易让人把长期许可误解为传统所有权。

```text
内容从实体介质转向数字许可
→ 购买记录绑定账号
→ 访问依赖商店、服务器与验证
→ 转让、继承和独立保存受到限制
→ 平台收入更可控
→ 长期承诺成为用户信任的关键
```

DRM 只是限制复制与访问的一种工具；平台中介所有权是账号、商店、许可和技术共同形成的权利状态。讨论它并不是否认数字分发的便利，而是提醒便利没有自动带来与实体商品相同的退出权。

## 两个主机案例把边界暴露出来

[[2025 - 全球 - Nintendo Switch 2 游戏钥匙卡]] 恰好说明这个概念不能套得过宽。它的内容本体需要下载，却不要求 Nintendo Account；首次启动后可以离线游玩，每次游玩又必须插卡。Nintendo 官方还说明，同一张卡插入其他主机也能使用，只需在该主机首次启动时重新联网下载。因此，不能说借用或转手能力已经被账号绑定取消；平台中介的是完整内容的首次交付和未来重装，不是每次访问都靠账号许可。

[[2026 - 全球 - PlayStation 实体光盘退出]] 则让新游戏更直接进入账号许可框架。两种路径都属于 [[数字分发锁定]]，但前者削弱实体访问凭证，后者保留实体钥匙、削弱的是卡片独立保存完整内容的能力。具体比较见 [[PlayStation 实体光盘退出与 Nintendo 游戏钥匙卡对比]]。

## 平台什么时候会付出信任成本

平时用户可能只感到购买方便、折扣多和无需换盘。等到商店关停、服务器停服、账号受限或游戏无法重新下载，权利边界才会显性化。平台若提供离线备份、跨平台携带、转售、继承或明确的关停补偿，用户的不确定性会下降。

对平台估值而言，数字许可带来的毛利和收入可预测性不能单独看。用户是否相信买过的内容长期可用，是资产负债表之外的信任变量。一旦数字购买被理解为弱所有权，迁移、盗版替代、监管诉求和品牌损耗都会增加。

## Web3 能不能替代平台中介

Web3 强调用户持有数字资产，回应了中心化平台的权利焦虑。但所有权凭证并不能自动解决版权、内容交付、反作弊、体验和商业分成，也不能保证服务器服务永远存在。

数字内容未来能否形成可转售、可继承和跨平台携带的标准，仍需观察。在缺乏法律强制和明确长期承诺时，用户应把平台持续运营与许可执行风险计入这类“资产”的价值。
