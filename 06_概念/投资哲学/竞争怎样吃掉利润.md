# 竞争怎样吃掉利润

市场很大、需求增长很快，并不保证参与者能赚到钱。只要产品容易模仿、客户容易切换、资本不断进入，新增价值就可能通过降价、加薪、营销、扩产和技术竞赛转移给客户、员工与供应商，股东最后只留下很薄的利润。

“竞争怎样吃掉利润”关注的不是竞争好不好，而是价值创造以后，利润怎样被降价、扩产和要素争夺搬走，以及这种侵蚀会持续多久。至于整条价值链中哪一层先把现金留下来，则由 [[价值链利润池]] 继续回答。

## Peter Thiel 的原话首先是在讲创业

Peter Thiel 在斯坦福创业课程中用“Competition is for Losers”强调：创业公司如果只是进入一个边界模糊、对手众多的市场，很难获得持久利润；更好的目标是通过独特技术、网络效应、规模经济或品牌先在一个小市场建立创造性垄断，再逐步扩张。

这句话的语境是创业战略与企业建立独特位置，不等于：

- 所有现实竞争都应被消灭；
- 任何垄断公司都值得投资；
- 市占率高就自然拥有护城河；
- 投资者可以忽略价格、治理和监管。

Thiel 的表达故意尖锐，作用是让创业者停止把“我们面对一个巨大市场”当成优势证明，转而说明公司究竟有什么别人做不到的事。

## 脑总怎样把它转成投资问题

脑总把“竞争”翻译成中国投资者熟悉的“内卷”：行业越热门、进入者越多，资本越容易把潜在利润花在扩产、补贴、抢人、广告和价格战上。即使社会需求确实增长，单个企业也未必能把增长变成股东回报。

他的判断顺序是：

```text
先确认商业模式本身能够创造价值
→ 再看竞争格局是否允许公司留住利润
→ 再看管理层会不会把利润合理分配
→ 最后判断市场价格是否已经透支这些优点
```

脑总用“轮胎厂混战，模具环节更容易留利”说明，利润池不一定在最接近消费者、市场空间最大的一层。投资分析应沿价值链上下移动，寻找议价权更稳定、客户转换更困难或竞争更少的环节。航空公司与关键零件商的差异见 [[航空公司与航空零部件供应商]]，轮胎厂与模具商的差异见 [[轮胎厂与轮胎模具供应商对比]]。

## 利润通常怎样被竞争搬走

竞争侵蚀利润常见于五条通道：

1. **价格竞争：** 产品差异小，客户只比较价格，降价直接压缩毛利。
2. **获客竞争：** 公司把利润投入广告、渠道补贴和销售佣金，只为维持同样的客户流量。
3. **产能竞争：** 行业高景气吸引扩产，供给追上需求后，设备利用率与价格同时下降。
4. **要素竞争：** 稀缺人才、原材料、航权、门店和流量平台拿走更多价值。
5. **创新竞赛：** 公司必须持续高投入才能不被淘汰，技术进步造福客户，但未必提高股东回报。

反过来，利润更可能留下来的位置通常具有认证和转换成本、局部网络密度、低成本规模、稀缺许可、关键但低成本占比的部件，或长期售后需求。[[沙漠之花投资]]正是用这些线索寻找“不显眼但能留利”的公司。

## 图谱的边界判断：竞争不是只有坏处

从社会与产业角度看，竞争也会迫使企业降低价格、改善服务、开发新产品并提高生产率。某个行业股东利润率不高，可能恰恰意味着大部分价值被消费者获得。把“竞争是失败者的游戏”直接当成公共政策结论，会忽略这一面。

垄断或强势市场地位也不是永久好生意：

- 监管和反垄断可能限制定价、并购和排他行为；
- 没有竞争压力可能造成成本膨胀、服务变差和管理松懈；
- 高利润会吸引替代技术、客户自制和跨行业进入；
- 公司可能用债务或高价并购放大原有优势，也同时放大风险；
- 依赖许可或特许经营的利润，可能在政策改变时被重新分配。

因此，图谱采用更窄的结论：**竞争通常会压缩可持续超额利润，但适度竞争也可能增强公司的创新能力；强市场地位只有在客户仍获得价值、监管允许、替代方案有限且管理层保持纪律时，才可能转化为长期利润留存。**

## 判断利润留存，不能只看利润率

一段时期的高利润可能来自周期高点、供给中断、会计口径或一次性提价。要判断它是否源于竞争优势，需要继续检查：

- 毛利率和投入资本回报能否跨周期保持，而不只是单年很高；
- 市占率提升是否同时带来现金流，而不是库存和应收账款膨胀；
- 客户为什么接受价格，是否因为产品不可替代而不是暂时缺货；
- 公司是否需要持续大额资本开支才能维持原地；
- 上游、员工、渠道和监管者有没有能力重新拿走利润；
- 管理层把留存利润用于回报股东、加强主业，还是高价并购和无关扩张。

## 哪些变化会推翻“竞争优势”

当以下证据出现时，应重新判断，而不是继续用“龙头”或“垄断”解释一切：

- 新进入者以更低成本或新技术通过客户认证；
- 客户集中采购、联合议价或开始自制关键部件；
- 产品标准化后，原有服务和定制价值下降；
- 监管要求开放接口、限制价格或重新发放许可；
- 公司市占率仍高，但毛利率、现金转换和客户留存持续恶化；
- 管理层依靠杠杆、回购或并购掩盖主业竞争力下降。

这个概念最终留下的不是“远离竞争”四个字，而是一套价值链问题：谁创造价值，谁有议价权，谁承担波动，谁最后把现金留下。

## 与价值链利润池怎样分工

[[价值链利润池]] 先定位“利润可能停在哪一层”，本概念再检查“这一层的利润为什么没有被竞争者、客户或供应商拿走”。两者连起来后，分析顺序是：

```text
画出客户、供应商、竞争者和资金流
→ 找到可能留利的瓶颈位置
→ 检查竞争会怎样侵蚀它
→ 写出优势失效的可观察条件
→ 最后单独讨论市场价格
```
