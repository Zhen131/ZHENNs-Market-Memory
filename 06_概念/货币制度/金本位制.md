# 金本位制

金本位制把一国货币按固定比率与黄金联系起来，并承诺在规定条件下用货币兑换黄金。多个国家都这样做时，各国货币之间的汇率也会围绕固定平价波动。它给国际贸易和长期债权提供了较强的汇率可预期性，却同时要求政府和中央银行为这个兑换承诺承担成本。

这套制度不意味着每张纸币背后都放着等额黄金，也不意味着银行不能创造信用。真正的约束是：黄金储备和兑换信誉不能长期被忽略。当资本外流、贸易逆差、银行挤兑或战争融资出现时，当局必须在保护黄金平价与保护国内经济之间作选择。

## 黄金外流为什么会变成国内紧缩

在经典金本位下，参与国以固定价格定义本国货币与黄金的关系。不同货币都锚定黄金后，彼此汇率也围绕固定平价波动。制度信誉来自一个承诺：符合条件的货币或银行负债可以按规则兑换为黄金。

这套制度并不意味着每张纸币背后都存放等额黄金，也不意味着货币供给不能变化。银行信用、黄金准备率和中央银行操作仍然会影响流动性。真正的约束在于：当资本外流或贸易逆差导致黄金流失时，政策当局通常需要提高利率、收紧信用、压低国内价格和需求，以保护兑换平价。

因此，金本位把一部分国际调整压力转移到国内经济：

```text
黄金外流 / 汇率承压
→ 中央银行提高利率并收紧信用
→ 投资、消费、价格与工资承压
→ 进口下降、出口竞争力恢复
→ 黄金流动和外部平衡改善
```

这条链条可能恢复平价，却会提高失业、违约和银行压力。

因此，金本位降低了汇率的一种波动，却可能把调整压力转移给国内利率、价格、工资、就业和债务人。政府是否愿意承受这些代价，是制度能否维持的关键，而不是黄金本身自动产生纪律。

## 第一次世界大战为什么迫使各国暂停规则

```text
战争爆发引发提款、资本流动与金融恐慌
→ 政府需要银行流动性和巨额战争融资
→ 维持黄金兑换要求收紧信用、保留黄金
→ 支持银行和财政要求扩大信用、降低融资约束
→ 两种目标发生冲突
→ 多国暂停或限制黄金兑换与跨境流动
```

在 [[1914 - 全球 - 第一次世界大战]] 中，战争把 [[金本位制]] 的核心矛盾暴露出来：国家既想保留国际货币信誉，又必须为生存动员资源。多个交战国选择牺牲或弱化兑换约束，把调整成本推迟到战后。

美国参战较晚，且因对欧洲出口与黄金流入而处于不同位置。战争扩大了美元在贸易融资与国际支付中的角色，说明同一制度冲击会因外部收支与金融地位不同而产生不同结果。

[[战时财政与货币扩张]]说明，这种暂停不是一个纯粹的货币技术决定。政府需要让银行继续支付、让财政取得军费、把黄金与外汇留给关键进口。维持兑换要求收紧信用，支持战争却要求扩大信用，两种目标无法同时充分满足。

这一过程也改变了[[政府债券]]的意义。政府即使名义上继续偿付债券，持有人仍可能因通胀、汇率或兑换限制而遭受实际损失。[[欧洲]]交战国与[[美国]]的外部收支和金融地位不同，不能用同一种“退出金本位”的叙事概括。

## 金本位不等于持有黄金

固定汇率可以锚定另一种货币或一篮子货币，金本位则以黄金兑换关系为基础。法定货币不承诺按固定价格兑换黄金，政策空间更大，通胀纪律更多依赖财政与制度治理。

一个国家持有黄金储备，也不等于实行金本位；投资者持有黄金资产，更不等于参与一种货币制度。金本位讨论的是货币发行、兑换和平价承诺，不直接给出黄金价格涨跌的投资结论。

正常贸易时期，金本位可以提高汇率可预期性；银行危机时，保护黄金与提供最后贷款人流动性会冲突；战争时，财政与进口需求可能压倒兑换规则；通缩时期，恢复旧平价又可能要求高利率、降价和降工资，使债务实际负担上升。资本越自由流动，纪律越快起作用，危机也可能传得越快。

名义制度和实际运行还可能分离。即使法定黄金平价仍在，若资本管制、兑换限制或行政定价长期存在，也不能据此认定货币仍能按原规则充分兑换。

## 这套制度留下了什么判断

- 货币制度的可信度不仅取决于法条，也取决于政府在战争、银行危机和社会压力下是否仍愿意承担维持平价的成本。
- “有黄金锚”不能替代对银行杠杆、财政赤字、储备充足度与兑换规则的分析。
- 固定平价会降低一种波动，却可能把调整压力转化为利率、失业、工资和债务实际负担。
- 研究历史债券回报时，必须同时看名义偿付、通胀、汇率与兑换制度变化。

- 英国、法国、德国和美国在战争期间“保留金本位外观”和实际限制兑换之间有何差别？
- 战后恢复旧平价如何与 1920 年代通缩、失业和债务压力相互作用？
