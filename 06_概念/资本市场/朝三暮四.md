# 朝三暮四

2026-10-30 [[英特尔]]大跌，理由之一是 PC 卖不动。三天后的 2026-11-02，[[脑总]]说这个担心不成立：内存涨价，想换电脑的人先等一等，今年不买，明年、后年还是要买。他拿一个成语收尾：「就就资本市场经常这样，你知道吗？经常出现这种朝三暮四的一个情况。」（见 [[涨价压住的需求只是推迟，市场像朝三暮四的猴子]]）

这里的“朝三暮四”，就是脑总的口头语：**需求的总量没变，只是先后挪了一下，市场却为“先给多少、后给多少”大喜大悲。** 他也反过来说“朝四暮三”。

## 是什么

典故出自《庄子·齐物论》：养猴子的人给猴子分橡子，说早上三个、晚上四个，猴子都发怒；改成早上四个、晚上三个，猴子都高兴了。总数没变，变的只是先后。今天日常说“朝三暮四”多指人反复无常，脑总用的是典故原来的意思。

他的用法有三个特点，都是从他的话里归纳的：

- **讲的是先后，不是多少。** 被推迟的需求还在，只是晚点来；被提前的需求也还是那么多，只是早点来了。
- **市场看的是眼前。** 这个季度少了，股价就跌，好像需求没了；这个季度多了，股价就涨，好像需求永远这么多。2026-11-09 他说：「我们说资本市场里面大家经常这么朝三暮四啊」。
- **有前提。** 这一条他 2026-11-09 讲得最清楚：先要搞清楚公司的壁垒高不高，它卖的东西是不是需求很稳定、几乎所有人都要，而不是会暴涨暴跌、会断崖式消失的伪需求。前提成立，市场的忽冷忽热才只是情绪。

它不是教科书里的术语。〔图谱的对照〕行为金融里讲投资者“短视”，过分看重最近几个季度的数字，把短期变化外推成长期，和这个说法相近；不同在于脑总把它落到了需求的先后上，而且只在需求稳、壁垒高时才这么看。他没有提行为金融，这是图谱的对照。

## 他怎么用这个词

**分辨推迟还是消失（2026-11-02）。** 英特尔的 PC 业务被内存涨价拖累，他说「那那就是需求暂时被压抑嘛」，这季度、下季度不买，「那明年会不会买嘛？」他还说，有些企业喜欢调节报表，就是去迎合市场「这种朝三暮四的这种需求」。最后一句是：「但是人类在资本市场又何尝不是一群猴子呢？」（见 [[涨价压住的需求只是推迟，市场像朝三暮四的猴子]]）

**有人把它推到整个消费电子（2026-11-06）。** 有人问：英特尔说笔记本销量被压抑，提到朝三暮四，和消费电子有关的公司里，比如[[任天堂]]，是不是也一样，这算不算正确的非共识。他说是，消费电子换机周期里的消息真空期，龙头估值低的时候就是机会（见同一张卡文末 11-06 那一行）。

**从推迟推到“拿来获利”（2026-11-09）。** 这一期他讲[[奈飞]]，说「就是我之前我前面说的就是朝三暮四」，又把典故讲了一遍，然后说在需求稳、壁垒高的前提下，朝三暮四和朝四暮三「是我们用来获利的办法」：「一旦朝三暮四就不高兴了啊，给你朝四暮三又高兴了，在这种情况下，我们可以用来获利啊」。奈飞是「一个很典型的这样一个容易让人朝三暮四的一个标的」：疫情时居家，大家集中去充会员，透支了一部分需求，之后增速掉到个位数，再叠上加息，股价双杀；需求恢复以后又涨回新高（见 [[奈飞还贵，竞争格局差，有机会 40 美元左右买]] 里 11-09 那一段）。

**用来分仓位（2026-11-09）。** 同一期他拿奈飞和 [[Visa]] 比：两家长期增速差不多，Visa 稳，奈飞大起大落。稳的当定海神针，「而这种容易有大波动的，那你应该利用」里面的朝三暮四（见 [[商业模式稳定的才当定海神针]]）。

**解释股价为什么一步三回头（2026-11-09）。** 讲任天堂时他说，它从低点涨上来「涨的一步三回头」，原因是「因为我们说的这个朝三暮四的问题还没有解决」：消费内存的价格还高，要等[[长鑫存储|长鑫]]的新产能进来（见 [[任天堂是游戏机里的苹果]]）。

## 和“政策刺激下的需求透支”有什么不同

[[政策刺激下的需求透支]]讲的是世界里发生了什么：补贴、减税让大家把未来几年的车、家电提前买了，刺激一停，行业面对需求断崖，供应链上还有坏账。朝三暮四讲的是市场怎么看这类变化。

| | 政策刺激下的需求透支 | 朝三暮四 |
|---|---|---|
| 是什么 | 一种反复发生的过程（模式） | 他看市场情绪的一个说法（概念） |
| 方向 | 需求被提前 | 需求被推迟，或被提前 |
| 总量 | 可能真的变少：刺激下买多了，之后几年还不回来，还有坏账 | 他假设总量不变 |
| 他的态度 | 透支以后的断崖是真的，要躲 | 市场把先后当成多少，是可以利用的情绪 |
| 例子 | 房地产退潮以后中国的汽车和家电 | 英特尔的 PC、任天堂、奈飞 |

奈飞 2020 年的疫情会员潮，两样都沾：先是居家把需求提前了，这是透支；之后增速掉下来，市场当成奈飞到了天花板，这是朝三暮四。分界在于总量：透支掉的那部分以后不会再来，朝三暮四里推迟的那部分以后还会来。

## 适用边界和失效条件

- **需求真的消失了，就不是朝三暮四。** 他自己划的线是“伪需求”“断崖式消失”。PC 如果被别的设备慢慢替代，就不是推迟，而是真的少了。
- **推迟也有代价。** 推迟一两年回来的需求，要打上钱的时间价值，这期间竞争格局也可能变。所以“需求不会消失”推不出“推迟没有代价”。这一条是图谱的推论，他没有这样说。
- **壁垒不够，等回来的需求可能被别人拿走。** 他把“壁垒够高”放在前提里，就是这个意思。
- **事后才看得清。** 一次下跌是朝三暮四还是需求真的变了，讲的时候不一定分得清，要等几个季度的数据。这一条是图谱的归纳。
