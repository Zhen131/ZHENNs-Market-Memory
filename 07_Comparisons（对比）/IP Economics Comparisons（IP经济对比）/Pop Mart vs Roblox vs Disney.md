# Pop Mart vs Roblox vs Disney（三种增长方式，不是三家同类公司）

脑总把泡泡玛特、Roblox 和迪士尼放在一起，想讨论年轻用户、复购、精神消费和 IP 的持续性。最有启发的不是判断谁更好，而是发现三家公司实际上依靠三种不同的增长机器：

- 泡泡玛特依赖 IP 运营、新品节奏、渠道和爆款持续出现；
- Roblox 依赖用户、开发者、内容供给和平台分成形成飞轮；
- 迪士尼把 IP 延伸到影视、流媒体、授权商品、主题乐园和邮轮。

这篇是 [[Desert Flower Investing]] 的延伸阅读。三家公司都不应被硬说成“沙漠之花”：它们所在领域高度受关注，增长与估值也更依赖未来预期。

## 泡泡玛特：持续制造“还想要下一只”

泡泡玛特不是只卖塑料玩具。它把艺术家或自有角色转成系列化产品，用盲盒、门店、线上渠道、展会和全球营销不断测试用户偏好。单个 IP 爆红能迅速放大收入，但商业模式能否长期成立，取决于公司能否在旧 IP 衰退前持续开发新品、扩展品类和管理授权。

公司 2025 年正式业绩显示，收入约 371.20 亿元人民币，同比增长 184.7%，并把 IP 运营与创意设计列为核心驱动。这证明当年增长很强，却不能单独证明复购率或单个 IP 的寿命。脑总口头提到的具体复购与用户消费数字，本轮没有在正式资料中取得同口径验证，因此不写成事实。

## Roblox：让别人持续创造内容

Roblox 更接近平台。用户花时间和 Robux 进入体验，开发者制作内容并通过平台变现，更多内容吸引更多用户，更多用户又提高开发者参与的价值。

2025 年 10-K 披露，平台拥有数以百万计的创作者、超过 1,400 万个活跃体验，平均日活用户约 1.27 亿；约 23,500 名创作者通过 DevEx 获得付款。这些数字支持“用户—内容—开发者”的飞轮，但平台也必须持续承担安全、审核、基础设施、开发者分成和青少年保护成本。

Roblox 的收入确认还存在递延：用户购买虚拟货币形成 bookings，收入按消费或预计使用周期确认。因此收入、bookings、现金流和会计利润不能混为一谈。

## 迪士尼：同一个故事跨多个消费场景

迪士尼的独特之处不是单一爆款，而是把角色和故事放进多个业务：影视与电视、流媒体、消费品授权、主题乐园、酒店和邮轮。2025 年 10-K 将业务分为 Entertainment、Sports 和 Experiences，也说明内容与 IP 会在多个渠道被开发和分发。

这种体系能够让一个 IP 多次变现，也会增加组织复杂度和资本负担。主题乐园与邮轮需要巨额长期投入，流媒体和体育版权面对激烈竞争；旧 IP 既是资产，也可能让公司在创作上过度依赖熟悉系列。

## 三种利润留存机制不能混成一个“IP 护城河”

| 公司 | 增长发动机 | 利润可能留在哪里 | 最容易失效的地方 |
|---|---|---|---|
| 泡泡玛特 | 新 IP、新品和渠道放大 | IP 筛选、供应链、门店与用户热度 | 爆款衰退、库存、仿品、海外执行和新品失灵 |
| Roblox | 用户与开发者双边网络 | 平台分成、虚拟经济和内容长尾 | 安全监管、开发者流失、获客成本、基础设施和用户年龄结构 |
| 迪士尼 | IP 跨媒体与线下场景延伸 | 授权、内容库、乐园和体验体系 | 创作疲劳、版权成本、重资产回报与组织复杂度 |

泡泡玛特需要不断证明“还会有下一批受欢迎的角色”；Roblox 需要证明平台能在支付创作者和保护用户后仍产生现金；迪士尼需要证明庞大 IP 体系的协同收益大于组织与资本成本。

## 市场现在怎么定价（2026-07-24 快照）

| 公司 | 适用口径 | 执行日附近快照 | 五个完整年度或可得历史 | 市场似乎已经相信什么 |
|---|---|---|---|---|
| 泡泡玛特 | P/E、EV/EBITDA、库存与现金流 | 股价约 160 港元区间，P/E 约 14.5 倍 | 2020 年上市后同源历史序列未可靠复原，留空 | 在 2025 年利润高速增长后，尾随倍数被快速增长的分母压低；市场仍在判断爆款能否延续 |
| Roblox | EV/Revenue、EV/Bookings、自由现金流 | 股价约 47.55 美元；按约 7.16 亿股估算，市值约 340 亿美元 | 上市不足五年，且本轮未可靠复原每年 EV 口径，留空 | 用 2025 年约 49 亿美元收入和约 68 亿美元 bookings 粗看，市值/收入约 6.9 倍、市值/bookings 约 5.0 倍；这不是 EV 倍数，只是透明替代口径 |
| Disney | P/E、EV/EBITDA、自由现金流与分部回报 | 股价约 92.83 美元，P/E 约 15—16 倍 | 疫情、流媒体投入和利润恢复使五年 P/E 分母不可比，本轮留空 | 当前价格未给予纯高增长平台倍数，但仍要求内容、体育和体验业务共同恢复现金回报 |

三个倍数不能横向排名。Roblox 尚不能用正常 P/E；泡泡玛特的高速利润增长会迅速改变尾随倍数；迪士尼的重资产体验业务与内容平台又需要分部看待。

## 可以迁移到其他公司的问题

1. 增长来自不断自产爆款、第三方创作者，还是旧 IP 跨场景复用？
2. 用户复购的是角色、随机机制、社交关系还是完整体验？
3. 公司必须持续支付哪些创作、分成、审核和资本开支？
4. 单个 IP 失速后，系统还能否产生下一轮内容？
5. 收入、bookings、现金流和会计利润分别在什么时候确认？
6. 当前估值买的是已经发生的增长，还是未来爆款与平台飞轮？

“IP 公司”只是起点。真正的研究要画出谁创造内容、谁拥有用户关系、谁承担爆款失败，以及同一个 IP 能被变现多少次。
