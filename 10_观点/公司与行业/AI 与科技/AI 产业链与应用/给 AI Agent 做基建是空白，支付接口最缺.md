> 但是现在AI agent需要的基建其实是不足的嘛。
>
> 就是现阶段整个整个金融行业这一块，其实还是挺空白的啊，为AI。做API可能还挺空白的。
>
> —— 2026-06-03 从巴菲特投资中石油看AI周期与估值

**一句话**：脑总认为，眼下大家在给大模型做基建，可 AI Agent（能自己替人办事的 AI 程序）需要的那套基建还很缺：查金融数据，缺一层可信、能直接给 AI 调用的数据；做支付，现在的账户全是为人设计的，Agent 需要自己能开、自己能用的账户。为 AI 做接口，他说可能是未来创业的一个重要方向。

### 他是在什么情况下说的

这是 2026-06-03 那期讲软件股的一段。前面有人问[[财捷]]、[[Workday]] 算不算被 AI 错杀，他给了一个判别法：业务把界面拿掉、换成接口还能不能存在（见 [[抗不抗 AI 看业务能不能 API 化]]）。说到能完全 API 化的公司，他想举个例子没举完，话锋一转，说这里有「一个值得大家去思考观察的方向」，「甚至有可能会成为未来创业的一个重要的方向」，于是讲了这张卡。讲完，他又回到能 API 化的公司，说 [[Snowflake]] 这类是被错杀的受益者。

〔背景〕他说的“空白”，大公司那时已经开始动手。2025 年 9 月 16 日，[[谷歌]]发布一套让 AI 代理替人下单付款的协议 AP2，用签名记录用户授权了什么、Agent 买了什么，好让银行和商家事后查账；万事达、美国运通、PayPal、[[Coinbase]] 等 60 多家公司支持，谷歌还另出了一个扩展，让 Agent 直接从加密钱包付款（PYMNTS）。第一版主要还是走银行卡。

### 他怎么说

**基建建在了大模型那一层。** 「就是给AI agent。做基建做基建啊，现在情况是给大模型做基建对吧？」大模型那一层有人在建，Agent 这一层不够。

**例子一：金融数据。** 「我自己做金融的，我举个最简典型的例子」。他做投研时，现在只能直接用大模型里的数据，「还还没有很好的这个金融数据的这个AI层」，也就是一个提供接口、让他的 AI 直接调取数据的地方。比如有人问费城半导体指数的历史估值，他想让 AI 把「PB从这个半导体指数诞生。到今天的历史PB，你给我绘制一条曲线出来」。大模型现在能做，「但是我担心他的数据不那么可信」；让它给出处，「它的出处往往是一些新闻来源有网上抓的」。要是有一个金融数据库能接进来，「进入数据库那会那会更扎实」。

**例子二：支付。** 「支付是个典型问题」。今天所有的支付账户和支付动作，「都是为人准备的啊，都是为人准备」：开户要身份证验证，「要身份证验证你一个人还不能够多开对吧？」想多开几个信用卡账户，还得找不同的公司去开。「那这其实是不符合AI的AI的使用需求的嘛」，因为每一个 Agent，「他都需要一个。无许可的账户，无许可让他自己去，让他自己去做很多这个支付的动作啊」，付款时还有各种验证。所以「这一这一块也是空白啊，也空白」。

**再往外推。** 整个金融行业，「为AI。做API可能还挺空白的」，「那就有可能有可能到某个阶段，基建就是围着围着这一块展开了」。企业那边的需求更是无穷无尽，「比如说电商行业，电商行业对吧？有有多少环节？」真到用 Agent 的时候，「最后你会发现缺乏好的API，你最后要用AI去操作。操作那个UI啊，就就跟按键精灵一样」。按键精灵是一种模拟鼠标键盘、替人重复点屏幕的小工具。他说这么干不对路：「这是人的习惯啊。这不是AI这个计算机的习惯」，计算机是靠接口工作的。所以「有大量的这个业务，其实需要接口化的」，而那些已经接口化的公司，「并且已经就是接口化的公司。SaaS他们其实来说的话是严重被错杀」。

### 拿什么来对照

〔图谱的对照〕他 2026-04-19 讲过另一种 Agent 的瓶颈：[[闪迪卡住了 AI Agent 本地存储的瓶颈]]。两张都在找 Agent 普及时缺什么，那张找的是硬件，Agent 在本地电脑上跑要大容量存储；这张找的是软件和金融的接口，Agent 要能自己取数据、自己付钱。那张已经落到一只股票上，这张他只说是一个方向，没有点名公司。

〔图谱的对照〕「无许可」这个词在币圈常用，指不用谁批准就能开地址、发交易。〔背景〕里谷歌给 AP2 出加密钱包扩展，走的正是这条路。他这一段没有提到币圈和稳定币，两件事是否有关，这是图谱的联想，他没有这样说。到 2026-07-26 他自己把这两件事连上了，讲的是 AI 之间的微支付和稳定币，见文末“后来又讲过”。

### 这个判断靠什么、怕什么

它靠 AI Agent 真的大量用起来，而且要自己办事、自己付钱。他在同一段里说，等 Agent 来了，可能一个人管很多个 Agent，调用一天 24 小时不停（见 [[抗不抗 AI 看业务能不能 API 化]]）；需求量起来，缺的基建才会有人买单。

它怕的有两样，都是图谱从他的话和〔背景〕里推出来的。一是空白被大公司补上：谷歌、卡组织、支付公司已经在定协议，留给创业公司的可能只是夹缝。二是监管不放手：他自己说，现在的账户要身份证验证、不能多开，这些规矩本来就是为了反洗钱、防诈骗；让 Agent 拿到「无许可的账户」，未必是监管愿意给的。

〔核对〕他没有引用数字。〔背景〕里谷歌 AP2 的支持方数量来自 PYMNTS 的报道，没有另找公司原文核对。

**一句话记住**：AI Agent 要替人办事，就得能自己查数、自己付钱；今天的账户和数据都是为人设计的，他认为为 AI 重做这一层接口，是一块还没人占好的地方。

## 后来又讲过

- 2026-07-26 演化不翻山、谷歌估值、币圈杠杆股、生物科技、航运、投票权、前锋中场后卫兼备（比 06-03 那次晚 53 天）：「AI很多AI的支付可能一次支付可能不到一分钱」「然后x402协议用的是usdc用的是circle发的b，但是是coin base牵头搞的」「最后价值捕获谁捕获的比较多。现在还不好断言啊」。这次是答微策略、Coinbase、Circle 三只币圈股那题时讲到的变量（见 [[三只币圈杠杆股：Circle 弹性最大，微策略先见底]]）。他说最近看了一篇讲 agentic 支付的报告，也就是 AI 和 AI 之间海量的微支付。人用的支付基本都在一块钱以上；刷信用卡，Visa、万事达收得不便宜，可能还有最低收费；中国的「微信和支付宝是收千一的」，提现还要手续费。AI 调用一次某个东西，付的钱可能不到一分钱，这些通道就不成立了。他说比特币扩容之争时，扩容派就畅想过比特币做数字经济里微支付的底座，但扩容派失败了，挑不起这个大梁，能挑起来的大概是硅谷的加密圈，也未必是加密圈：「这个东西不一定需要公链」，私链、联盟链也许都行，「它毕竟不是要来做一个货币」。眼下他看到比较好的方案是 x402 协议：Coinbase 牵头，用的是 Circle 发的 USDC，两家在他看来有「父子的关系」；价值最后归谁还说不准，要看 USDC 跑在哪条链上，「但是可能支付coin base是想让它发生在自己的base链上面啊」；光是 USDC 发行量扩大，Circle 的收入就会增长，要是还能赚到支付手续费，想象力更高。要跟踪的是它会不会发展超预期，以及「有没有其他巨头出来又搞一笔其他新的协议来跟这一块竞争」。他说「这个是币圈比币圈之外AI产生的一个变量啊」。**这次补的是两点**：一是 06-03 说的支付空白，已经有 x402 这样的协议在做，并且落到了稳定币上；二是价值归 Coinbase 还是 Circle，他认为还说不准。〔核对〕Coinbase 2025-05-06 发布 x402，把网页里闲置多年的“402 需要付款”状态码拿来做稳定币付款，Circle、AWS、Anthropic 等参与（Coinbase；Payment Expert）。和他说的 Coinbase 牵头、用 Circle 的 USDC 对得上。
