> —— 2026-09-25 AI助手利好CPU、Meta像字节、股票代币与DeFi、抄巴菲特莱纳作业、爱马仕

**一句话**：脑总认为，AI 助手这条赛道，大家第一反应是去找握着入口的公司，可谁有流量谁都能做，入口没什么壁垒；最确定的受益者是硬件，尤其是 CPU。按一台电脑里的价值量，CPU 至少和内存并驾齐驱，可 CPU 相关的市值眼下只有约 1 万亿美元，比 GPU 和内存都小得多，所以还有空间。他也说这只是他的猜想。

### 他是在什么情况下说的

这是 2026-09-25 中秋节那天直播开场讲的第一点。他说今天结合市场上刚发生的事来讲，第一个题目刚好是一位朋友的问题：最近 [[Meta]] 出了一个 AI 助手 Muse，股价暴涨；提问的人猜 AI 助手是未来人机交互的方式，互联网大厂握着流量入口，能把 AI 嵌进工作、生活、娱乐，有先天优势；他还说[[腾讯]]的 WorkBuddy 用户增长很快、腾讯估值不贵（这两句是提问人的话）。他问：AI 助手这个赛道，什么公司最受益？

脑总的第一反应是：「这就是我们一直在打call的英特尔的利好来了吗？」他说之前给大家讲过英特尔的逻辑，指的是两周前的 09-11 和四天前的 09-21 那两期（见 [[英特尔是免费的台海战争期权，3 浪还在后面]] 文末那两行）。

〔背景〕Meta 9 月 8 日前后推出 Muse，这是一个能自己替用户办事的 AI 助手：发邮件、订行程、管付款、排日程，跑在自己的虚拟机上，关掉应用也能接着干活。先在美国上线，有单独的应用，也能在 WhatsApp 里用；基础功能免费，用得多要付每月 20 美元或 100 美元。第二天 9 月 9 日，Meta 股价涨 6.5%，收在 654 美元；10 日摩根大通把它调到“增持”（TIKR，2026-09-10）。

### 他怎么说

**入口谁都能做。** 他说大家想到的第一层是哪些公司掌握入口，但 Meta 的 Muse 这种东西创业公司也能做；它跟 [[Manus]] 当时做的东西「我觉得就差不多吧」，从 Manus 到 Muse 再到腾讯的产品，「我觉得都都差不多，对吧？」（他还提了一个在 Manus 之前的产品，转写听不清是什么，这里不写）。「任何有流量的公司啊」，特别是有办公流量的，都能做：[[微软]]能在自己的办公系统里做一个，[[谷歌]]能在谷歌文档、谷歌邮件里做一个。所以入口公司没什么壁垒，而「英特尔是有壁垒的，就现在硬件硬件产能稀缺嘛」。

**AI 助手要在本地干活。** 现在用的 AI，是完全集中在数据中心里算的，但他说这不一定是 AI 最终的样子。AI Agent 就是另一种形态：「它要在本地运行很多任务的，它要在它要调用调用本地的很多资源」。

**拿一台高级电脑比价值量。** 他让大家设想一台高级一点的电脑：把显卡上的显存拿出来，「显存跟内存条放在一起。都是记忆体」；风扇不值几个钱，去掉；剩下 GPU 芯片和 CPU 芯片，比它们的价值量。他的结论是「CPU至少价值量是跟内存是并驾齐驱的」；GPU 看打游戏的需求高低，好一点的游戏电脑里，「价值量可能是内存和。或CPU的两倍啊」。

**再拿市值去比。** 内存已经被充分挖掘、充分定价了，他不敢说涨到头，但「就肯定不低估了，就大家肯定已经认识充分的认识到它的重要性了」；「但CPU的话就就还没有很多人。呃，认识它是不是重要？」他的算法是：把跟 CPU 有关的几家凑一凑，[[AMD]]、[[英特尔]]，再加上可能有些关系的 Arm，而且要把各家和 CPU 无关的业务剔掉，单独算 CPU 业务的占比。拿去比的，一边是 GPU，据他说「五万多亿」，把别家的 GPU 也算进来，「我算他60000亿吧」；一边是记忆体，据他说三四万亿。CPU 这一块呢，「CPU现在可能也就10000亿吧，我估计对吧，充起来也就10000亿」（单位都是美元，据他说，未核实）。所以「还有空间嘛啊，还有空间」。整个 CPU 的市值，他说「有机会到个30000亿」，没给时间。

**他自己留的余地。** 这个价值量比例「我也只是猜，我也只是猜」，他只是按一台日常干活用的个人电脑里各部件大概的占比去推。

**英特尔已经不是最安全的时候。** 他说「但只是说这个地方股价谈不上特别安，特别安全，谈不上了啊」：以前「就市场认为它的它的这个晶圆厂还是累赘」，「那个时候是特别安全」。现在的情况是，「就有可能利好会接踵而至，不断的不断的来验证我们原来的这个猜想」，不管是涨价的消息，还是个人助手被大规模采用。

**问答里又说了一遍。** 同一期后面有人再问 AI 助手什么公司最受益，他说刚才讲过了，「我其实最看好的是CPU」；其他的说不明白，「AI助手这个东西有流量的可能都能做，有流量可能都会做」，说不定哪天「苹果可能说不定直接来一个硬件」，做一个硬件集成的 AI 助手。他自己戴眼镜，「我现在就特别想要一个这种AI助手性的眼镜」，看过国内的产品，没有太强的购买冲动。

### 拿什么来对照

〔图谱的对照〕这套价值量推理，四天前的 2026-09-21 他刚讲过，写在 [[一个品类的市值天花板约 5 万亿美元]] 文末 09-21 那一行：三家内存厂的总市值不该超过英伟达，CPU 相比英伟达「弹性还挺大的」。两次的比例说法不完全一样：

| | 2026-09-21 | 2026-09-25 |
|---|---|---|
| 设想的电脑 | 主要办公用的家用电脑 | 高级一点的电脑，以游戏电脑为例 |
| CPU 和 GPU | 「价值量是一比一」 | GPU 可能是 CPU 或内存的两倍 |
| CPU 和内存 | CPU 高于内存 | CPU 至少和内存并驾齐驱 |
| 拿来比的市值 | 5 万亿 | GPU 约 6 万亿、记忆体三四万亿、CPU 约 1 万亿 |

两次设想的机器不同，比例也就不同；方向是一样的，都是 CPU 的市值相对它的价值量偏小。

〔图谱的对照〕同一种推理他 2026-04-19 用在存储上：[[闪迪卡住了 AI Agent 本地存储的瓶颈]] 说，AI Agent 要在本地电脑上跑，闪迪的 SSD 卡住了本地存储。这次是同一个本地运行的前提，落到了 CPU 上。

〔图谱的对照〕说入口没壁垒，和他 03-19 说的 [[AI 的大机会在垄断交互入口，聊天框不是终局]] 不冲突。那张说的是，谁能发明出新的交互方式、垄断下一代入口，才有大机会，聊天框还不是那个入口；这次说的是，眼下这批 AI 助手谁有流量谁都能做，所以没有壁垒。他这次提到的苹果直接做一个硬件 AI 助手、AI 眼镜，正是那张卡说的“交互方式还没定”。

〔图谱的对照〕英特尔那一半，他在 [[英特尔是免费的台海战争期权，3 浪还在后面]] 里讲了半年：04-26 那次已经说过「但是就最安全的一段就已经没有了」，这次说谈不上特别安全了，是同一个意思。

### 这个判断靠什么、怕什么

它靠三件事。一是 AI 助手真的走向在本地运行，要调用本地的计算资源，而不是一直全在数据中心里算。二是他猜的价值量比例大致对：CPU 在电脑里至少和内存一样重要。三是市场还没认识到这一点，所以 CPU 相关公司的市值还有追上去的空间。

它怕的，图谱从他的话里归纳出几件：他自己说比例「只是猜」，猜错了，空间就没那么大；AI 助手如果一直主要在云端跑，本地 CPU 需求起不来；英特尔已经从晶圆厂被当成累赘时涨了很多，他说不再特别安全，利好要一步步兑现，兑现慢了股价会反复。

**复盘日期怎么定**：他说 CPU 整体市值「有机会到个30000亿」，没给时间。图谱估一年后复盘，`review_on` 写 2027-09-25，这个日期是估的。到时看：AMD 的 CPU 业务、英特尔、Arm 加起来的市值离 3 万亿美元还有多远；AI 助手是不是大规模普及、是不是拉动了 CPU 的需求和价格。

〔核对〕他说 GPU「五万多亿」，和 9 月 21 日收盘英伟达约 5.61 万亿美元对得上（CloudNews）。同一天 AMD 约 1.005 万亿、英特尔约 6459 亿、Arm 约 3449 亿，三家加起来约 2 万亿；他说剔掉无关业务后 CPU 相关约 1 万亿，各家 CPU 业务占多少这次没有查。记忆体三四万亿没有逐家查当天的市值。转写里「这个md的那部分剔除出来」那半句，是不是指把 AMD 的 GPU 业务剔出来，已问 Zhen；「龙龙虾之后」指的是哪个产品，也已问 Zhen。

**一句话记住**：AI 助手的入口谁都能抢，硬件产能却是稀缺的；脑总押的是 CPU，理由是它在电脑里和内存一样重要，市值却只有内存的三分之一左右，但他也说这个比例是猜的。
