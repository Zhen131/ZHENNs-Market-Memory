> 但是对于日本这些IP公司，像像任天堂，像万代这些，那我觉得是是很稳的很稳的这些IP，它这些IP都几十年了。
>
> 这这些资产都已经被当成老登了，万代万代这样的都被当成是老登了。
>
> —— 2026-06-25 日本股市、科学仪器、生物平台公司、美股代币、费哲、重啤、奈飞、小商品城、TransMedics、Zoetis，杠铃策略与足球阵型

**一句话**：脑总认为，任天堂、万代这类日本 IP 公司手里的 IP 都有几十年历史，生意很稳。它们现在便宜，不是 IP 不行了，而是 AI 把电子产品的成本推上去、资金也离开了这一块，市场把它们当成了“老登”；据他说万代只有 17 倍 TTM 市盈率，他觉得不贵。

### 他是在什么情况下说的

这是 2026-06-25 直播的第一题。这期他先说要把前三次直播欠的问题清一清，第一个问题是有人问日股有没有推荐的股票。他说自己最近在看日股，方向就是上一期讲[[泡泡玛特]]时引出来的：「我就沿着上一期讲的这一类方向。去研究日本的这种娱乐产业类的股票」，任天堂「肯定是绕不过的」，接着就打开了万代的行情。他还说「我觉得我觉得日股日股还真的可以花花花精力」。

同一段里他讲了三件事：日本公司为什么整体便宜（见 [[日本破净股的重估还早，才轮到防务股]]），任天堂和苹果一档（见 [[任天堂是游戏机里的苹果]]），以及这张卡讲的万代这类老 IP 公司。

〔背景〕万代南梦宫在他说话前一个多月公布了截至 2026 年 3 月的财年业绩：营收 1 兆 3482 亿日元，营业利润 1895 亿日元，都创了新高；高达系列的销售也大幅增长。但它给下一财年的预测是营收 1 兆 3500 亿日元、营业利润 1850 亿日元，营收持平、利润略降（万代南梦宫财报说明会资料；FilingReader）。

### 他怎么说

**先拿泡泡玛特作对照。** 他说泡泡玛特的难处在于，从一个 IP 爆发到下一个 IP 爆发之间，「这个交接期。的这个业绩的波动，我是我是觉得现在我看不清楚」；它现在的市盈率后面还会不会往下掉，「之前拉布布这波爆发要有多少可能会还回去，我这个是不清楚的」，「不好把握，不好把握」。

**日本的老 IP 不一样。** 任天堂、万代这些公司的 IP「都几十年了」：「你高达高达都多少年了」，任天堂的塞尔达也很多年了，马里奥更不用说，「马里奥都可能说都是爷爷级的IP了」。IP 越老，越不用担心下一个接不上。

**老 IP 还能翻新。** 他讲了拓麻歌子，也就是万代的电子宠物（日文名他当场说不出来）。「万代的这个电子宠物原来是我，我小时候玩过嘛，我小学的时候玩过」；后来「万代把它做成彩屏的还可以连还可以联网」，他说「现在万代甚至还把电子宠物给复兴了」，有孩子的朋友可以去看看。他还猜，「说不定以后他还会给他做出一些。AI相关的东西嘛」，AI 式的养成也许能加进来，随即自己说「这当然这说说远了哈」。

**为什么便宜：被当成了老登。** 他看了万代的走势：「已经都承压了一段时间了，对吧？二五年之后都已经跌下来一段时间」，现在处在过去上升通道的下轨上。他的估计是，「这这些资产都已经被当成老登了」。他说万代「本来是妥妥的妥妥的小登」，后面又说它「已经不是小登了」（后半句转写听不清）。原因有两层：一是 AI 带来的成本上升，这些公司「是无论是电子电子产品相关的，导致就是成本的上升」；二是资金「也相对来说，抛弃了这一块啊」。结果是「导致这个万万代的PE也就十几倍吧」，他当场查了一下，「啊17倍ttm 17倍」（据他说，未核实）。

**结论：不贵，而且稳。** 「17倍。都不贵啊，都不贵，而且就都还是比较稳的」。接着他把这一类叫作精神消费品，说这是一条没有上限的赛道（见 [[人类是追求社交地位的猴子，温饱后追消费符号]]）。

他没有说买，只说自己最近在看；同一题末尾他特意说明，日股这些谈不上推荐，「我自己看的也还比较早」。

### 拿什么来对照

他自己的对照是泡泡玛特：

| | 泡泡玛特（他的说法） | 任天堂、万代（他的说法） |
|---|---|---|
| IP 的年纪 | 拉布布这一波刚爆发 | 高达、塞尔达、马里奥，几十年 |
| 他看得清吗 | IP 交接期的业绩波动看不清，估值可能还要往下 | 很稳 |
| 估值 | 他没给数 | 任天堂约 18 倍、万代 17 倍 TTM（据他说，未核实） |

像的地方是两边卖的都是 IP 带来的精神满足；不像的地方是，泡泡玛特的业绩取决于下一个 IP 能不能接上，老 IP 公司已经证明过自己能一代代传下去。

任天堂在这张卡里只作对照：它和苹果一档、AI 电子周期压住消费电子的那层意思，写在 [[任天堂是游戏机里的苹果]]。

〔图谱的对照〕15 天前的 2026-06-10，他把泡泡玛特的下一个看点放在能不能在美国白人主流里再爆一个 IP（见 [[泡泡玛特已成 IP 平台，下个看点是在白人里爆]]），讲的是新 IP 怎么打开新市场；这张卡讲的是另一头：已经活了几十年的 IP，市场却按“老登”给价。两张卡并排看，一个赌增长，一个买确定性。

### 这个判断靠什么、怕什么

它靠两件事，都是他说出来的：老 IP 还有生命力，能像拓麻歌子那样翻新；压低估值的是 AI 带来的成本上升和资金流向，不是 IP 本身。照他讲任天堂时的说法，等 AI 电子的价格降下来，消费电子的成本压力会松开。

它怕的，图谱从他的话和〔背景〕里归纳出两点。一是成本压力持续得比他想的久：〔背景〕里万代给下一财年的利润预测已经略降。二是“被当成老登”可能持续很久：市场的钱一直追 AI，老 IP 公司再稳也可能长期不涨。他说「都不贵」，没有说会马上涨。

〔核对〕万代 17 倍 TTM 市盈率、「二五年之后都已经跌下来一段时间」的走势，这次没有找到他说话那几天的可靠数据，没有核实。拓麻歌子是万代 1996 年起推出的电子宠物，2023 年推出的 Tamagotchi Uni 能连 Wi-Fi（Wikipedia，仅作参考），和他说的「彩屏」「联网」对得上。

**一句话记住**：IP 越老越稳；当这样的公司因为成本和资金流向被当成老登时，便宜的是价格，不是生意。
