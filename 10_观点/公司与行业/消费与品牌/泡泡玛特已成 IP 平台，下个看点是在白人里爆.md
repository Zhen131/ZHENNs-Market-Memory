> 它就变成了一个。IP艺术家与消费者的平台。顶级的IP艺术家的作品。最后肯定要走他的平台。
>
> 美国在白人主流里面再搞一个爆的IP，那么它的市值还能再上一个台阶
>
> —— 2026-06-10 逃顶与做空、AI落地瓶颈、泡泡玛特、加拿大银行股

**一句话**：脑总认为，[[泡泡玛特]]把产能、渠道、品牌都搭好以后，已经成了顶级 IP 艺术家和消费者之间绕不开的平台，同行追不上；接下来要看的，是它能不能在美国白人主流里再爆一个 IP。它现在值多少钱，他说拿不准。

### 他是在什么情况下说的

这是 2026-06-10 直播里答“泡泡玛特，中国未来可能会有类似迪士尼的公司吗”的后半段。前半段他讲泡泡玛特是什么生意：不像迪士尼，像茅台和奢侈品（见 [[泡泡玛特对标茅台和奢侈品，不是迪士尼]]）。这一段讲它在行业里的位置和以后看什么。他的依据，很多来自一位做潮玩的朋友，他说对方是同行里「联创级别的高管」。

两个月前他不是这样看的。2026-04-09 他说泡泡玛特没有网络效应，「我就是不知道他能不能成长为一个IP工厂」（见 [[Roblox 护城河很牛，估值已到前几年底部]]）。这次他说它已经是 IP 艺术家的平台，说法变了，原因他自己交代了：是听了那位朋友的解释以后。

〔背景〕到他说话时，泡泡玛特已经在海外卖得很好：2025 年美洲收入 68.1 亿元，增长 748.4%；欧洲及其他地区 14.5 亿元，增长 506.3%；亚太 80.1 亿元（格隆汇）。但 2026 年一季度，美洲增长降到 55% 到 60%、欧洲及其他地区 60% 到 65%，华尔街见闻的标题写的是“欧美市场增长放缓”；港股年内仍跌约 16%（华尔街见闻，2026-05-12）。

### 他怎么说

**平台搭完，别人追不上。** 他说泡泡玛特搭完产能、渠道、品牌、「逼格」以后，「它就变成了一个。IP艺术家与消费者的平台。」「你如果是最牛逼的艺术家，你的作品想要触达。最广泛的大众」，只能去找它。那位朋友「他跟我承认就没法追赶你」，所以研究它「核心就看这个赛道就行了」：赛道以后还行，别人就追不上。

**英语世界为什么做不出来。** 英语世界有资本，资本可能也愿意烧钱，但「差在供应链」：手办很多要工人一个一个手动上色，很多细节要艺术家待在工厂打磨，「这就是中国的优势了」。所以在他看来它是「第二名无法望其项背的一个平台」。

**两个爆款 IP 各验证了什么。** 他转述那位朋友的说法：泡泡玛特爆过两个 IP，一个是 Molly，一个是 Labubu，「Labubu验证了泡泡玛特。商业模式的成功，就这套东西已经做成了。这个模拟验证了他有出海能力啊」（转写如此，见〔核对〕）。后面他自己又说，它「已经验证他有成功出海能力」。

**以后看什么。** 「拉布布还是主要是亚裔在买」：它的美术调性偏亚裔、走萌的路线，和漫威、DC 那类美漫风格不一样；哪怕店开到伦敦、纽约、多伦多，「里面买的主要还是主要还是亚裔」，在白人和拉丁裔里还没爆。如果能在美国白人主流里再爆一个 IP，「那么它的市值还能再上一个台阶」。他设想了一个画面：白人基金经理的孩子天天缠着爸妈买某个玩偶，爸妈一看是哪家公司做的……他说这种情况现在还没出现，「那这这是就是后面的观察点」。

**估值拿不准。** 「我我自己觉得现在估值的话，我是有点拿不准的。」拿不准的是 Labubu 这一波进来的买家「会会有多少会有多少复购的」，里面有多少是「黄牛式的需求」。但他也说，这家公司以后「是有弹性的企业」。

### 拿什么来对照

最直接的对照是他自己两个月前的说法：

| | 2026-04-09 | 2026-06-10 |
|---|---|---|
| 泡泡玛特是什么 | 没有网络效应，不知道能不能成为 IP 工厂 | IP 艺术家与消费者的平台，同行追不上 |
| 为什么这么看 | 拿 Roblox 的用户和开发者飞轮作对照 | 听了同行前高管讲产能、渠道、品牌和供应链 |

〔图谱的对照〕他说的“平台”和 [[Roblox]] 那种平台不太一样。Roblox 上的游戏大多是开发者自己做、自己上架，平台主要收分成；泡泡玛特的“平台”是艺术家要靠它的工厂上色、靠它的门店和渠道卖货，做哪个、做多少由它挑，库存也由它背。像的地方是，好的创作者都会往人最多、条件最好的地方去；不像的地方是，泡泡玛特这边每个新 IP 仍要它自己押注。

### 这个判断靠什么、怕什么

它靠他说的两件事：这条赛道以后还行；中国手工上色、艺术家驻厂的供应链，英语世界短期补不上。

它怕的，一是他自己点的估值疑问：黄牛需求退了、复购低，现在的买家就撑不住现在的价格。二是那个观察点迟迟不出现：Labubu 一直只在亚裔里卖得好，白人和拉丁裔市场打不开。他没给时间，所以这里不建成预测卡；以后入库时可以看看他有没有再提白人市场。

〔核对〕Molly 和 Labubu 哪个验证了什么：转写里是 Labubu 验证商业模式、「模拟」（可能是 Molly）验证出海。按常识，和他自己 2026-04-04 的说法（第一轮上涨是 Molly 推动的，这一轮是 Labubu，Labubu 是在海外社交媒体上火起来的）对照，像是说反了；这里照转写写，已问 Zhen，等他定。Labubu 买家「主要是亚裔」，这次没有找到可靠数据。

**一句话记住**：脑总这次把泡泡玛特看成 IP 艺术家绕不开的平台；它还能再上一个台阶的那一步，是在美国白人主流里爆一个 IP。
