**一句话**：脑总认为，[[马斯克]]的 X Pay 杀进来以后，面向个人用户的支付这一块会更内卷，[[Circle]]、[[PayPal]] 这些公司一段时间里都会难受，最后谁赢短期看不出来。PayPal 已经被苹果、谷歌的支付挤压多年，市盈率到了个位数他也不敢买，除非便宜到「令人发指」。但他也说，支付是出大牛股的领域，值得长期关注。

### 他是在什么情况下说的

这是这一期后半段的一个提问。有人问：马斯克推出美版微信支付 X Pay，拿 6% 的活期收益做推广，力度很大，感觉是在抢 PayPal、费哲（[[Fiserv]]）这类支付服务的蛋糕，怎么看。

他一开口就说「这就是这就是我说的」，接着讲的是三天前那期的话题：熊市里巨头拿补贴抢稳定币的利息（见 [[熊市里巨头补贴抢利息，Circle 会被双杀]]）。所以这一题在他那里，是同一件事的又一个例子：大家都在抢 C 端用户手里那点钱。

〔背景〕X Pay 在报道里叫 X Money，是马斯克的 X 做的支付和存款产品。2026-04-14，美国参议员沃伦写信给马斯克，追问 X Money 什么时候推出、提供哪些银行服务、会不会发稳定币，以及对消费者和金融稳定有什么风险（Payments Dive）。据事后报道，6 月底它先对一小批 Premium+ 付费用户开放内测（Bitcoin.com News）。三天前的 2026-06-30，Stripe 等一百多家公司宣布推出稳定币 Open USD，承诺把储备收益分给合作方，Circle 当天大跌（Forrester，见上面那张卡）。PayPal 这时的估值很低：几家数据网站显示，6 月它过去一年的市盈率在 7.5 到 8.4 倍之间（仅作参考）。

### 他怎么说

**X Pay 抢的不只是 PayPal。** 他说马斯克「不但会抢其他的蛋糕，还会抢这个。尤其会抢你像circle站的公司的蛋糕，对吧？」他还提到一个转写作 ousd 的东西，也在抢蛋糕（图谱的推测：多半是三天前讲过的 Open USD，待确认）。何况「这个币圈当前没钱赚嘛」，这些抢蛋糕的出来，Circle 这类公司「后面很可能会看到下滑」。至于提问里提到的费哲，他说它主要做 B 端，和主要面向个人用户的 X Pay「好像跟他有点不一样吧」（见 [[Fiserv 是金融业的 AWS，比 Block 安全]]）。

**PayPal 为什么便宜也不敢买。** 他说：「我配票现在很便宜很便宜，但是。这是真不敢买配票，是真不敢买」（「配票」是转写对 PayPal 的写法）。原因是「它这几年已经被Google Pay、Apple Pay挤压的非常厉害了」。据他说，它的市盈率已经是个位数（未核实），但「基本面基本面感觉我说实话也看不到，看不到什么特别大的转机」，「除非是已经。便宜的令人发指的地步了，否则的话真真不敢买」。

**什么叫进入绝对价值。** 他用这个词说明什么价钱才敢买一家在衰退的公司：「你只要只要它的衰退，我已经我已经预计你会失败。」就算看到了它生命周期的终点，「但是我只需要你在活着的这个过程里面能够把市值这个钱挣回来就行了」。PayPal 现在「还没进入绝对价值的情况下面啊」，所以股价「还会更难过」。他说这正是基本面分析要做的事，而 PayPal 的问题出在护城河：它「没有太强的护城河啊，被这个苹果和谷歌这么一冲」，就有些动摇了。

**马斯克也难赢。** 「虽然twitter是超级APP啊」，但 X 拿来做支付、去和苹果、谷歌比，他觉得「好像也没那么容易」，因为「苹果跟谷歌掌握的东西好像更底层一些」。结果是「这块大家有一段时间可能会大家都不那么好过」。苹果、谷歌倒不在乎，「家大业大」，支付在它们的业绩里「业绩占比很很很少啊，微乎其微」。

**但这是个出大牛股的赛道。** 他把话收回来：「这个领域支付这个领域值得长期关注。制出大牛股的领域。」他数了一遍：「从VISA mastercard对吧？到这个PayPal、Block」，从「信用卡支付到互联网支付啊。再到以后会有什么各种别的支付方式。」

**他要回头查的事。** 最后他说「我要看一下xpxp在不在space x的业绩里面，对吧？」，要评估它在上市公司里影响有多大，「因为它已经把x装进了space x嘛」（X 先并进 [[xAI]]，xAI 2026 年 2 月又并进 [[SpaceX]]）。这一点他当场没有结论。

### 拿什么来对照

他自己排了一条支付的传承：[[Visa]]、[[万事达]] → PayPal、[[Block]] → 以后还会有新的支付方式。每一代都出过大牛股，但新一代来了，上一代里做 C 端、护城河薄的那家最先受伤。

| | PayPal | X Pay | 苹果、谷歌的支付 |
|---|---|---|---|
| 站在哪一层 | 搭在卡组织网络上的一层 | 搭在 X 这个超级 App 上 | 握着手机操作系统，「更底层一些」 |
| 他怎么看 | 被挤压多年，便宜也不敢买 | 入局后大家都难受，谁赢看不出来 | 不在乎，支付占业绩微乎其微 |

〔图谱的对照〕他 2026-02-19 讲过 [[支付网络靠双边效应，互联网只能当它的分销商]]：Visa、万事达的护城河是商家和持卡人互相吸引的网络，互联网支付没能重建底层网络，只成了分销商。这一期的话是那张卡往下推一步：分销商之间又会被更底层的苹果、谷歌和新来的 X 挤。不同的是，那张卡讲的是谁有护城河，这张卡讲的是没护城河的那一层什么价钱才值得碰。

〔图谱的对照〕「绝对价值」那几句，和他讲的 [[要么拿得准，要么白菜价，不碰中等风险]] 是同一个思路：拿不准的生意，只有便宜到就算它慢慢死掉、活着时也能把市值挣回来，才算白菜价。PayPal 在他眼里还没便宜到那一步。

### 这个判断靠什么、怕什么

它靠两件事：一是苹果、谷歌握着手机这一层，PayPal 和 X 这类搭在上面的支付很难绕开它们；二是 C 端支付拼的主要是补贴和利息，谁都很难赚到超额的钱。

它怕的是 PayPal 自己找到转机，或者 X 真把超级 App 的流量变成了支付的护城河。他自己也说「短期你根本看不出来，最后谁会胜利」，所以这张卡讲的是一段时间里大家都不好过，没有判谁输谁赢。他也没给时间。

〔核对〕提问说的 6% 活期收益，和报道对得上，但当时 X Money 还只对少数付费用户开放（Bitcoin.com News）。他说 PayPal 市盈率个位数，和几家数据网站 6 月约 7.5 到 8.4 倍的数字对得上（仅作参考，没有对照财报算）。X Pay 有没有装在 SpaceX 的上市公司里，他说要回头查，图谱也没有查。

**一句话记住**：支付是出大牛股的赛道，但站在别人地基上的那一层最先挨挤；PayPal 便宜，脑总说还没便宜到「绝对价值」。
