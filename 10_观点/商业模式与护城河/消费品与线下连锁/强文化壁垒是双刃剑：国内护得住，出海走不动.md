> 说的好听，是强文化说的不好听的话就是。你你让老外去喝这种。一股一股一股，这种馊馊抹布味道的酱香味啊，说实话不够普世。
>
> 也有也有很强的这个盈亏同源嘛，我们知道盈亏同源啊，那他们在国际化里面呢，基本上就是国际化不动。
>
> —— 2026-07-16 SpaceX、Tesla、黄金、WKL.AS、Oracle、银行、消费、生物医药、正确对待财报

**一句话**：脑总认为，茅台、海天、东阿阿胶这类公司靠的是强文化壁垒：在国内，竞争对手学不来，用不着政府出手保护；可同一个壁垒也让它们走不出国门。好处和坏处出自同一个地方，他管这叫盈亏同源。

### 他是在什么情况下说的

这是 2026-07-16 那期一个问答里的一段。有人问茅台、伊利、美的、重庆啤酒、海天、东阿阿胶谁的商业模式高一档，他说这几家估值都算合理，接下来主要看国际化（见 [[A 股消费龙头估值已合理，接下来看能不能出海]]）。然后他一家家讲为什么有的走得出去、有的走不出去，这张卡装的就是这一段里那条能搬到别的公司上用的道理。

〔背景〕拿茅台来看，出海这条路在他说话前确实还很窄。2025 年上半年茅台海外营收 28.93 亿元，同比增长 31.29%（环球网，据搜索摘要）；同一年茅台酒的全年收入是 1465 亿元（新华网）。海外涨得快，但底子很小（图谱的推论）。

### 他怎么说

**茅台：口味不够普世。** 「我觉得茅台国际化是比较受阻的，对吧茅台？」引用块里那句「强文化」就是在讲它：酱香味老外喝不惯。他拿自己作例子：自己不怎么喝酒，年轻时跟朋友斗酒硬喝过，各种酒里勉强喝得来的是龙舌兰和伏特加，因为闻着不反胃；「中国白酒普遍让我觉得啊，就就闻到闻到我就就有点反胃了」。龙舌兰度数也高，也辣嗓子，可就是没有那股让不喝酒的人胃里翻涌的味道，「这一点上我觉得很难国际化」。

**海天：品类窄，打法搬不出去。** 「海天相对来说嗯，要弱势一些」，他说这是品牌过去的路线问题。一是品类本身窄，「本身酱油这个品类，这个品类就是相对来说比较狭窄的」，主要在亚洲，尤其东亚，而日本已经有龟甲万；调味品「有有有强文化属性」。二是打法：海天原来的方式「就是强渠道」，直接绑定大量的餐馆，「通过通过餐馆渠道归顺了很多人的舌头」，据他说六成多的餐馆用的是海天的酱油（未核实）。这套打法在国内很灵，「按照中国。国内那套打法去做国际化的话，基本上是很难做得动的啊」。舌头被归顺是什么样子，他也拿自己说：从小吃惯了海天、李锦记这类生抽，换了龟甲万，「我觉得吃的光咸不够鲜了」。

**东阿阿胶：只有华人吃。** 「你东阿阿胶的话可能最多国际化到香港嗯，南南洋华华社国际化到到这些地方里面」，「可能日本人都不吃阿胶，韩国人可能都不可能都不吃阿胶。啊，这一块的国际化潜力真的更差了。」

**为什么说是双刃剑。** 「东阿阿胶那不就说的这属于说的好听，是强文化壁垒啊，这是双刃剑，双刃剑。」中国市场高速发展的时候，海天、茅台、阿胶这种「有极强的保护，它不需要不需要你政府去出手保护，对吧？乳制品企业可能还需要政府出手保护」。毛利已经很高，按理竞争对手会进来，但「竞争对手玩不来这种强文化的东西啊」，所以这层保护在国内发挥到了极致。也正因为如此，到了国际化，就像引用块第二句说的，「基本上就是国际化不动」（这四个字的意思见 [[盈亏同源]]）。

**伊利是另一回事。** 伊利出海难，他没归到文化上，讲的是牛奶这门生意本身。「中中国人自己都。自己有条件都不想喝中国牛奶啊，你你不能指望它变成雅培美赞臣」；牛奶有运输半径，现在越来越流行低温的巴氏奶，「那越越低温奶的话，你越难国际化了，对吧？」能出海的是奶粉，可他觉得伊利的奶粉国际化也有难度，「而且也没有很好的奶源吧」。

### 拿什么来对照

他一口气讲了五家，放在一起看，挡住出海的东西不一样：

| | 挡住出海的是什么（据他说） | 是不是强文化 |
|---|---|---|
| 茅台 | 酱香口味不够普世 | 是 |
| 海天 | 品类窄、东亚已有龟甲万、绑餐馆的打法搬不出去 | 是，调味品有强文化属性 |
| 东阿阿胶 | 日本人、韩国人可能都不吃 | 是 |
| 伊利 | 运输半径、低温奶、奶源、国人自己不信任 | 不是 |
| 重庆啤酒 | 运输半径，但可以收购当地酒厂 | 不是，他说有潜力但还没开始 |

另一头是[[美的集团|美的]]：空调没有口味问题，他说美的已经扩张成功（见 [[美的强在渠道和出海，格力输在接班]]）。

〔图谱的对照〕运输半径在他嘴里也是一把双刃剑。讲啤酒、水泥时他说，东西运不远，外来者只能在当地建厂，谁兼并完一个运输半径，那片市场就归谁（见 [[运输半径短的行业，兼并完就是区域垄断]]）；这一次同样的运输半径，成了伊利、啤酒出不去的原因。和强文化一样，护住国内的东西，也挡住了出海，不过这层对应是图谱的推论，他这次没有这样说。

〔图谱的对照〕同样是带文化属性的消费品，他对[[泡泡玛特]]的看法不一样：他说泡泡玛特的下一个看点是在白人里卖爆（见 [[泡泡玛特已成 IP 平台，下个看点是在白人里爆]]）。差别可能在于，潮玩的 IP 不绑在中国人的口味和习惯上，而酱香、酱油、阿胶绑得很紧。这是图谱的推论。

### 这个判断靠什么、怕什么

这条道理靠的是一个前提：口味和习惯很难被改造。只要老外不接受酱香、不吃阿胶，这些公司的天花板就在华人圈。

它会在两种情况下失效。一是文化真的输出了：口味是可以被培养的，他自己就说海天靠餐馆「归顺」了中国人的舌头，海外要是有类似的渠道，结论就可能变。二是公司换了打法，比如用收购当地品牌的方式出海，就像他说重庆啤酒可以走的那条路。

〔核对〕他说六成多的餐馆用海天酱油，这次没有查。他提到的龟甲万本身是日本酱油品牌，它在海外卖得怎么样，可以拿来检验“调味品出不了海”这一条，这次没有查。

**一句话记住**：让一家消费公司在国内谁也打不进来的那堵文化墙，也会把它自己挡在国门里面；看这类公司，要把护城河和天花板放在一起看。
