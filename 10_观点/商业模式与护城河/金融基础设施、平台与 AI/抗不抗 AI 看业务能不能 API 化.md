> 你把这个UI去去掉，换成API，完全不影响你这个业务的。存在这是最强的，最弱的就是你这个业务，一旦换成这个纯UI哈纯UI啊，没有任何API属性在。
>
> 就最近这些涨得很好的有反转态势的公司都符合我说这个特征，就是它的业务API化。
>
> —— 2026-06-03 从巴菲特投资中石油看AI周期与估值

**一句话**：脑总看一家软件公司扛不扛得住 AI，问的是：把它给人看、给人点的界面（UI）拿掉，只留一个让程序直接调用的接口（API），这门生意还在不在？还在的最强，AI Agent 越多，调用它的就越多；不在的最弱，这类公司眼下正处在杀逻辑阶段，不要碰。

### 他是在什么情况下说的

这一期前半场讲 AI 有多大，他刚说完 AI 够得上城市化的量级、中间还会有基建，接着说「我建议大家强烈观察一个点，现在市场比较忽视的哈」，正好接上一个提问：有人问[[财捷]]和 [[Workday]]，Workday 那边还提到招聘端的裁员潮和企业 IT 支出，问这两家算不算被错杀。他先给了态度：有一类公司「逻辑真的有问题，不要急着介入」，然后讲了这张卡的判别法。讲完，他顺着「接口」讲到给 AI Agent 做基建是个空白（见 [[给 AI Agent 做基建是空白，支付接口最缺]]），再讲 [[Snowflake]]，最后用[[冯柳]]的下跌三分法收尾：这类公司处在杀逻辑阶段（见 [[下跌分三种：杀估值可抄，杀业绩等拐点，杀逻辑别碰]]）。

〔背景〕他说话前两周，这三家公司刚好各自交了财报，走势分成了三样。财捷 5 月 20 日公布截至 4 月的季度业绩，营收约 86 亿美元、增长 10%，但报税软件 TurboTax 这一季只增长 7%，全年预期也下调到约 7%，同时宣布裁掉约 17% 的员工；第二天股价跌了约 20%，年内已经跌了一半多（Motley Fool）。Workday 5 月 21 日公布季度营收 25.42 亿美元，增长 13.5%，维持全年订阅收入指引（Workday 新闻室），第二天股价一度涨了近一成（Motley Fool，只看到摘要）。Snowflake 5 月 27 日公布产品收入 13.3 亿美元、增长 34%，上调全年指引，又宣布五年在亚马逊云上花 60 亿美元，盘后涨了约 36%（TIKR、FX Leaders）。

### 他怎么说

**先分清是哪一种跌。** 他说财捷有一部分业务「是这个UI强UI导向的公司」，例子是给个人报税的 TurboTax。报税无非是流程复杂，普通人学一学也能会，「无非就是要付出一些认知成本」；「而AI的一个作用就是把认知成本极大的降低了啊」，「就哪怕是普通人的话，你在AI的帮助下可以自己报了啊」。所以虽然财捷的业务、利润都还在，「这个利润还在增长，利润还在增长。但是我觉得市场这个担心是有道理的啊」。

**判别法就一问。** 「你的这块业务能不能搞成API，不影响你这个业务存在」。界面拿掉、换成接口、业务照样跑的，是最强的；一换成接口业务就没了、纯靠界面的，是最弱的。他说这和卖给个人还是卖给企业没关系：「你这个软件不行，不一定是toc还是tob，核心就是你是不是一个强UI的一个东西？」现在 AI 还替代不了，只是因为 AI 还不够好，「等下一代模型出来说不定。你这个软件就不行了」。所以这部分收入投资时要按归零算（见 [[买入时只给保底定价，增长当彩票]]）。财捷里也有不怕的部分：给专业税务人员用的软件，要有人背锅，AI 替代不了（见 [[AI 不能背锅，企业软件可以]]）。

**拿这个标准挑公司。** Workday 比财捷好一些，但他说「也不是最好的」；「最好的那种是。就是它的业务可以高度的高度的API化啊，所有业务都可以API化」。他想举一个例子，没说完就转了话题（见〔核对〕）。

**能 API 化的，AI 来了反而受益。** 他说这类公司「之前是严重被错杀了」，例子是 Snowflake：「Snowflake这类公司是之前是严重被错杀了」，「而且不仅被错杀，他们是高度AI受益的」。理由是收费方式：很多软件按账号收费，一个员工配一个账号，一家一万人的公司买一万个；等 AI Agent 来了，可能一个人管一百个 Agent，「他可能就需要100万个账号」。而且「人一天只工作八个小时。AI agent可能调用的话，24小时不间断的调用啊」，「会产生新的商业模式出来」。Snowflake「就已经是暴涨了」。他的总结就是引用块里那句：最近涨得好、有反转态势的，都是业务能 API 化的；反过来，「如果你的业务API化会影响存在啊，那其实是要打一个大大的问号的」。

**为什么界面会被杀。** 以前人通过视窗和电脑交互，AI 改成了用语言交互；AI Agent 更不需要视窗，「但AI agent的话，它其实是自动运行的程序」，「计算机是通过接口接口工作的啊」。所以「AI在杀UI这一块我觉得是啊，是能够成立的啊，当前在那杀逻辑阶段，那就那就不能够去碰了」。软件行业不是铁板一块，「你要看它的商商业模式的区别」。

### 拿什么来对照

〔图谱的对照〕这张卡和他 03-15 讲的 [[专业软件的壁垒是可视化窗口，AI 能绕过它]] 说的是同一层东西：软件卖的是一层给人用的界面。但两次的口气不一样：

| | 2026-03-15 | 2026-05-31 | 2026-06-03（这张） |
|---|---|---|---|
| 说界面会怎样 | 优势可能大大减弱，但「可视化中介这个东西本身来说不会消失」，终局是两者结合 | SaaS 已经反转，例外是「主要是通过UI来实现功能的SaaS」 | 纯界面那部分按归零算，正处在杀逻辑阶段，别碰 |
| 用来做什么 | 解释 Adobe 的护城河为什么松了 | 说明哪类 SaaS 还没被放过 | 一条挑公司、排强弱的通用判别 |

三天前那次（见 [[SaaS 抗 AI 靠嵌入工作流和沉淀行业隐性知识]] 文末 05-31 那一行）只点了一句例外；这次把它推成了通用的判别，还把能 API 化的一头说成 AI 的受益者。03-15 那次留了「不会消失」的余地，这次没有再提。算不算改口，待 Zhen 定。

〔图谱的对照〕Snowflake 这一段和 [[AI 冲击的是中间执行环节，前后两端反而增强]] 同向：那张说软件公司若能改成按用量收费，业绩还可能腾飞；这张说本来就按调用收费、能 API 化的公司，会被 AI Agent 的调用量推着走。和 [[颠覆风险的外塔观察法]] 放在一起看，两者都是判断会不会被颠覆的办法：外塔法看最先挨打的那一层动没动，API 化看这门生意离开界面还能不能活。前者是观察，后者是拆业务。

### 这个判断靠什么、怕什么

它靠一个前提：以后调用软件的越来越多是 AI Agent，而 Agent 走接口、不看界面。他说得很明确，Agent 是「自动运行的程序」。

它怕的有两头，都是图谱从他的话里推出来的，他没有这样说。一头是人还要看、还要改的地方：如果很多工作最后仍要人在界面上确认，界面的价值就不会归零，这正是他 03-15 讲过的两者结合。另一头是能 API 化的公司未必都赚到：按账号收费改成按用量收费，Agent 的调用量能不能换成收入，要看公司定价的本事和客户的预算。他自己也只说「未来可能会有巨大的估值，估值反转」，用的是「可能」。

还要注意他给的是方向，不是买点。财捷那类他说别碰；Workday 他说已经比较充分地反映了预期，但也不是最好的；只有 Snowflake 这类他说被错杀，而它在他说话前一周已经大涨。

〔核对〕他想举的那个能完全 API 化的公司，转写只有「tw l.」几个字母，没说完就转了话题，已问 Zhen，这里不写公司名。他说 Snowflake「就已经是暴涨了」，和 5 月 27 日财报后约 36% 的涨幅对得上。

**一句话记住**：看一家软件公司怕不怕 AI，把它的界面拿掉想一想：生意还在，AI Agent 越多它越忙；生意没了，那部分收入就当它归零。
