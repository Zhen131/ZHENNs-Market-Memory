# 观点索引

一张观点卡记录某人的一个主张，第一段就是他的一两句原话。他反复讲的同一个意思只有一张卡，每讲一次在卡上记一笔；「反复讲的」视图按次数排，最上面的就是他最核心的想法。下面的清单由视图自动生成。预测类观点另见 [[预测追踪.base|预测追踪]]。

观点卡按它回答的问题，分在下面几个文件夹里（规则见 AGENTS.md 第 8.5 节）。一个文件夹到 20 张卡时，开头会有一篇导览。

| 文件夹 | 它回答的问题 |
|---|---|
| 商业模式与护城河 | 什么样的生意好，壁垒从哪来 |
| 估值与赔率 | 多少钱值得买，还能涨多少 |
| 选股与仓位 | 买谁、配多少、什么时候卖 |
| 中国经济与产业 | 中国的产业和政策怎样影响投资 |
| 全球化与地缘 | 贸易、技术、国与国的关系怎么变 |
| 公司与行业 | 对某家公司、某个行业的具体判断 |
