# **课程摘要**

本次直播主要围绕美股、港股、A股的“本位资产”进行讲解，首先介绍了比特币作为本位资产的重要性，并以此类比其他股票市场。接着，通过足球教练的比喻，解释了如何根据市场情况动态调整仓位，包括防守、稳健、进攻等不同策略。然后，详细分析了美股的第一个时代——铁路和基础设施时代，介绍了梧桐树协议、卡内基、范特比尔德等历史人物和公司，并展示了联合太平洋等股票的K线图。此外，还对比了中美铁路的差异，并提到了巴菲特在铁路股上的投资。接着，介绍了A股的对应资产——水电，并列举了长江电力、华能水电等公司，强调了其稳定性和低估值。最后，提到了对未来投资的一些看法，包括对制造业、新能源、航运等行业的分析，以及如何选择合适的股票进行投资。

## **美股本位资产学习笔记**

<a id="本位资产概念与投资框架"></a>
### **1. 本位资产概念与投资框架**

本位资产是指在特定市场中，投资者应将核心仓位配置于具有稳健护城河和长期价值的资产，类似于币圈将比特币视为本位资产。在其他风险资产上赚取的收益，最终应转换为本位资产来计算整体回报。这种策略适用于美股、港股和A股等多种市场。

本位资产的配置可比喻为足球阵型管理，其中现金仓位比作替补席，防守仓位对应后卫（低风险资产），稳健白马仓位对应中场（如蓝筹股），进攻性高成长仓位对应前锋（主题性股票）。投资者应根据市场环境动态调整阵型（如532、433、442等），在市场艰难时侧重防守，在市场向好时增加进攻。

投资时应优先识别并投资市场中的“简单题目”，即那些历史悠久的、具有深厚护城河的资产，避免受社交媒体热点误导。这些资产有助于理解护城河、价值投资和国家经济繁荣本质，而非盲目信仰指数。

<a id="第一个时代铁路时代1792年至今"></a>
### **2. 第一个时代：铁路时代（1792年至今）**

<a id="历史背景与垄断逻辑"></a>
#### **2.1 历史背景与垄断逻辑**

美股证券行业起源于1792年梧桐树协议，标志着正式大规模证券交易的开始。铁路时代是第一个本位资产时代，以卡内基和范特比尔德为代表，核心资产为铁路公司。铁路的垄断逻辑源于自然壁垒：铁轨铺设后，新建平行铁路在经济上不可行，且通货膨胀和行政壁垒（如土地审批）进一步强化垄断，这与品牌或网络效应垄断不同。历史上，美国曾有上千家铁路公司，经过破产并购整合，现仅存7家年收入超5亿美元的一级铁路公司，部分为加拿大公司但可在美股交易。

1. **定价权**：美国铁路价格市场化，可提价转嫁成本，而中国铁路价格被刻意压低以维持国际竞争力。
2. **维护需求**：铁轨需持续维护，折旧周期长，但商业模式弱于水电。

<a id="买点与技术分析"></a>
#### **2.3 买点与技术分析**

铁路股的买点策略基于均线系统：

1. 回踩十年均线是罕见机会（约5-6年一次），如加拿大国铁在2020年回踩后上涨。
2. 上升通道下轨道为买入信号，例如加拿大国铁（CNI）在近期回踩下轨道后右侧上涨约10%。支撑逻辑：股息提供安全垫（如加拿大国铁），不涨时可持股收息。

<a id="水电与铁路商业模式对比"></a>
#### **3.2 水电与铁路商业模式对比**

水电商业模式优于铁路，体现为：

1. **资产属性**：水电大坝折旧期40年，但实际寿命超百年（如胡佛大坝），折旧完后盈利能力增强；铁路铁轨维护成本高。
2. **能源效率**：水电为清洁能源，成本最低；新能源（光伏、风电）为“垃圾电”，因发电与用电高峰错位（光伏白天发电、晚上用电），依赖储能增加成本。
3. **政策安全性**：水电作为央企资产，政策风险低；电价扰动优先影响火电或光伏。公式支持：水电股息率（\$=% \$）普遍高于国债利率（如中国十年期利率约1%），提供安全边际。

### **4. 第二个时代：石油与工业时代**

<a id="石油时代洛克菲勒时代"></a>
#### **4.1 石油时代（洛克菲勒时代）**

石油时代以洛克菲勒为标准石油代表，通过产业链整合和成本优化实现垄断，但1911年被反垄断法拆分。尽管拆分，碎片公司（如雪佛龙、美孚）仍具垄断性。巴菲特的投资（雪佛龙）验证其价值。

主要石油公司分析：

1. **雪佛龙**：油价低迷周期（2009-2020年）股价原地踏步，但股息丰厚；当前随油价波动。
2. **艾克森美孚（XOM）**：渠道垄断（加油站覆盖生活半径），近期逆油价下跌上涨；估值接近铁路股，股息率更高。
3. **风险点**：油价跌至50美元可能压制股价；技术分析显示突破年线上升通道上轨道后连续加速（如2022-2023年），为卖出信号。

A股映射为中国海油（垄断油田），而中石油侧重炼化（贵价油买单风险）、中石化侧重炼化，表现较差。石油商业模式优势：

1. **对比矿业**：石油为快消品（烧完即无），矿为慢销品（可回收），故石油周期性更弱，易讲稀缺故事。
2. **渠道壁垒**：加油站实现地域垄断，但无品牌溢价。

<a id="a股制造业对标"></a>
##### **4.2.2 A股制造业对标**

A股优秀制造业公司较少，仅少数具全球竞争力：

1. **福耀玻璃**：全球汽车玻璃市场份额三分之一，工厂布局美国；股价涨势稳健，专注消费属性。
2. **美的集团**：国际化路线（如Costco销售），职业经理人管理；对比日本大金电器，在衰退期仍为牛股。
3. **风险对比**：格力电器因企业文化问题（如股东冲突）衰退；制造业估值易受周期影响（如工程机械）。

<a id="投资原则与周期管理"></a>
### **5. 投资原则与周期管理**

<a id="护城河与仓位管理"></a>
#### **5.1 护城河与仓位管理**

护城河本质是客户粘性：为何钱由特定公司赚取而非竞争者（如铁路铁轨不可复制、水电站资源垄断）。评估方法：

1. 强护城河资产（铁路、水电）优于弱护城河（制造业），因后者易被卷成本（如三一重工挑战卡特彼勒）。
2. 入手时机：回调至重要均线（如五年均线或十年均线）建仓，十年均线可加倍仓位。

仓位管理核心是组合再平衡：

1. **策略**：保持高仓位，现金留作子弹；高位连续加速突破时卖出一半（如美孚2022年案例），低位资产（如加拿大铁路）调入仓位。
2. **逻辑**：避免难题（如航运强周期），专注简单题（农业需求稳定）；只跨一米栏（巴菲特原则）。

<a id="周期行业投资"></a>
#### **5.2 周期行业投资**

强周期行业（航运、汽车）投资原则：

1. **航运**：周期长（船舶寿命影响供给），需等全行业亏损多年且产能出清（如船舶报废）。
2. **汽车**：当前需求透支（国补政策），未来可能减少300万辆；回避高杠杆公司（如比亚迪潜在风险）。公式应用：均线系统为核心，年线支撑价值（\$\$ 指标指导买点）。

周期变量简化：选择需求永恒行业（如农业），避开因素复杂领域。
