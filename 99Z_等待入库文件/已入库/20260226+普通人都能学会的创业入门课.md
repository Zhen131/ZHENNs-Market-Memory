#  **普通人如何通过执行力和贴脸竞争实现创业**

# **课程摘要**

本次直播主要围绕普通人如何通过执行力和贴脸竞争实现创业展开。首先，主播强调了创业并不一定需要高智商或高学历，普通人通过学习和执行也能成功。其次，主播指出打工是一种最差的商业模式，因为售卖个人时间有上限且竞争激烈。为了改善这一状况，普通人应考虑将时间加工成商品来卖，即做自己的生意。接着，主播提出了一种反主流的创业建议，即普通人应先从贴脸竞争开始，找到一个已经赚钱的商业模式，然后完全复制其细节和模式，通过执行力抢到其10%的市场份额。这种方法不需要智商和运气，只需要执行力。此外，主播还强调了高等教育在创业中的局限性，并建议普通人应先入场、先竞争，然后逐渐走向反竞争。最后，主播还分享了如何通过自媒体等渠道获取流量和客户，并建议普通人应多关注流量和成交技巧，而不是过于关注产品本身。

<a id="创业入门与商业模式学习笔记"></a>
## **创业入门与商业模式学习笔记**

<a id="打工的商业模式分析"></a>
### **1. 打工的商业模式分析**

打工作为一种商业模式，本质上是直接售卖个人时间，但其效率低下且存在诸多局限性。

<a id="售卖个人时间的缺点"></a>
#### **1.1 售卖个人时间的缺点**

打工涉及将一天固定的八小时劳动时间售卖给单一买家（即雇主），这意味着时间无法同时多卖给多个客户，上限明显。例如，高薪职业如医生或律师，尽管收入较高，但售卖时间依然受到物理限制：一个人不可能无限工作，也无法通过并行售卖提升收入。此外，为了获得售卖机会，个体需投入多年教育成本（如医学院或法学院的学习），这增加了前期投入和时间代价。

更严重的是，入职后还需面对持续竞争：新毕业生源源不断涌入同一赛道，他们精力更旺盛、更能加班，而随着年龄增长（如成家生子），个体精力下降，容易被淘汰。这种竞争在低门槛职业更为激烈：例如程序员行业无准入门槛，导致毕业生不断内卷；律师行业在中国虽门槛提高（现需法本学历），但早年门槛低时竞争同样激烈。总体而言，打工的模式特点是低效、高竞争和有限收入天花板，是“能赚到钱但最差的商业模式”。

<a id="商业模式改进方向"></a>
#### **1.2 商业模式改进方向**

要优化商业模式，核心是将时间加工成商品售卖，而非直接出售时间给他人加工。这相当于从打工转向做生意：通过加工劳动时间（如创建产品或服务）直接销售给终端用户，从而突破时间售卖的限制。例如，自媒体从业者将知识加工成课程售卖，而非仅为公司打工。这种转变避免了打工的单一买家依赖和收入上限问题。

<a id="创业入门贴脸竞争策略"></a>
### **2. 创业入门：贴脸竞争策略**

对于普通人创业入门，推荐采用“贴脸竞争”策略，即直接复制已验证的成功商业模式，而非追求创新或颠覆。

<a id="贴脸竞争的逻辑与优势"></a>
#### **2.1 贴脸竞争的逻辑与优势**

主流叙事（如乔布斯或马斯克的故事）强调天才和颠覆性想法，但这对普通人“有毒”，因为它让普通人误以为创业必须依赖创新，从而不敢行动。实际上，大部分成功生意是“闷声发大财”，通过执行力复制现有模式。贴脸竞争的核心是：找到一个已在赚钱的个体（预期收入为你目标的10倍），研究其模式细节并复制，目标抢占其10%市场份额或新增份额（若行业增长）。这有四大优势：

**市场验证**：对方已证明用户存在、定价合理、形式可行。

**低风险执行**：不需智商或运气，仅需执行力；例如，抖音内容火了，可复制到视频号或小红书，利用市场隔离获取份额。

**避免创新陷阱**：普通人缺乏商业训练，创新易失败；复制则降低试错成本。

**反竞争起点**：执行中可发展自身特质（如专业背景），最终走向反竞争（建立护城河）。

<a id="贴脸竞争的操作步骤"></a>
#### **2.2 贴脸竞争的操作步骤**

**选人标准**：

目标对象年收入约为你预期的10倍（如想年赚10万，找赚100万的人）。

其用户画像你需有资格服务（如专业匹配）。

优先选择一人模式（无团队依赖），便于复制。

**研究维度**：分四个层面分析其生意细节：

**流量端**：如何获客（平台选择、内容频率、爆款逻辑）。

**信任端**：如何建立人设和证明专业性（如内容设计、私域运营）。

**产品端**：售卖内容（定价策略、用户分层、引流款与利润款设计）。

**转化端**：成交方式（直播销售、私域导流或公域直接成交）。

**执行目标**：像素级复制形式（初期确保高度相似），争取赚到其收入量级的10%。例如，AI卖课市场庞大（汉语世界潜在用户超1亿），复制一个年赚300万的人，目标年赚30万并不难。

<a id="贴脸竞争的成功案例"></a>
#### **2.3 贴脸竞争的成功案例**

案例一：私董会朋友通过电商和自媒体赚到A9身价（估计数十亿）。07年淘宝卖虚拟商品，14年运营50个斗鱼主播，后转小红书电商——始终聚焦执行力强的“生意”，而非传统创业。案例二：网易邮箱部门员工（2012年）发现淘宝店主需推广而微博博主可接广告，通过撮合双方起步。初期月赚几百元，辞职全职后三个月赚1000万——验证了贴脸竞争的可复制性（无壁垒但执行力强）。

<a id="自媒体的核心作用"></a>
### **3. 自媒体的核心作用**

自媒体是普通人创业的通用基础设施，因其获客成本低且具复利效应。

<a id="自媒体的优势"></a>
#### **3.1 自媒体的优势**

传统获客方式（如广告投放、线下门店或经销商）存在痛点：烧广告成本高、口碑传播慢、经销商压缩利润或不愿合作。相比之下，自媒体通过内容自然引流，优势显著：

**低成本获客**：内容创作边际成本低，历史内容持续带来新用户。

**复利效应**：每条内容积累流量资产，长期降低平均获客成本。

**通用性强**：适用于多种一人生意模式，如知识付费、工具销售或咨询。例如，本地服务（如遛狗）或蓝领工作虽无需执照，但依赖找到客户；自媒体解决了流量问题。

<a id="自媒体的应用场景"></a>
#### **3.2 自媒体的应用场景**

自媒体作为底层能力，支撑多种变现形式：

**知识付费**：卖课或Newsletter。

**数字产品**：工具模板或资源包销售。

**咨询服务**：如留学或移民咨询（需注意牌照）。

**实体产品**：结合1688一件代发（如电子烟弹销售）。关键点在于：产品本身次要，流量驱动成交。许多人本末倒置，过度纠结产品而忽略获客。

<a id="流量与内容的关系"></a>
#### **3.3 流量与内容的关系**

对初学者，流量优先于内容：先掌握流量技巧（如平台算法和爆款逻辑），赚到钱后再优化内容建立壁垒。例如，张雪峰高考志愿咨询（收费1万/次）或立党计算机教育，均靠流量而非内容深度起家。

<a id="高等教育的局限与替代路径"></a>
### **4. 高等教育的局限与替代路径**

高等教育在创业视角下常沦为“庞氏骗局”，因它消耗资源却未提供实用商业技能。

<a id="高等教育的成本与缺陷"></a>
#### **4.1 高等教育的成本与缺陷**

教育投入巨大：小学到高中补习费几十万人民币，大学本科二三十万，时间成本超十年。但产出有限：

仅换取“打工入场券”，且不一定成功（如北上广白领租房后无积蓄）。

浪费创造力黄金期：年轻人学习力强、执行力高，若用于生意试错（失败三次），积累的经验远超名校教育。本质上，这是“沉重枷锁”，因它未训练执行力或市场理解，反灌输“中产阶级白领思维”——依赖文凭而非实战。

<a id="替代路径实战优先"></a>
#### **4.2 替代路径：实战优先**

反竞争（如巴菲特路径）需要本钱（资本、口碑），普通人无资格；应先通过贴脸竞争入场。理想教育应聚焦：

**学校期间**：恋爱、找伙伴创业（如宿舍团队低成本执行）。

**资源分配**：昂贵教育不如天使投资或风投，将资金用于实战。核心逻辑：打工仅适合两头——履历镀金型（便于融资）或低门槛学习型（如跨境电商打工后单干）；中不溜岗位（无光环无壁垒）性价比最低。

<a id="创业执行细节与误区"></a>
### **5. 创业执行细节与误区**

成功创业依赖执行力，需避免常见错误。

<a id="执行力恢复与维持"></a>
#### **5.1 执行力恢复与维持**

执行力无需复杂训练：立即行动是关键，尤其自媒体类似“短线操作”，正反馈（如点赞增长）会上瘾。步骤：

选定可复制对象（如旅居YouTuber）。

像素级分析其内容（逐帧研究平台、频率、人性痛点）。

持续迭代（总结爆款原因），形成比游戏更强的物质反馈循环。

#### **5.3 常见误区与规避**

### **6. 问答环节知识点提炼**

<a id="创业与打工的选择权衡"></a>
#### **6.1 创业与打工的选择权衡**

高薪职位（如Tech工作）是否辞职创业取决于机会成本：打工有上限（中国年薪60-70万难突破），管理岗才达百万；而生意年赚几十万更易（如自媒体私域收款无税）。建议：

清闲打工中研究创业。

两头选：镀金型（融资便利）或学习型（如跨境电商打工后单干）。

<a id="资产配置观点"></a>
#### **6.2 资产配置观点**

**人民币vs美金**：现汇率破6.9，能换多换；A股资产高估无机会，美股跌后更优（如软件股）。

**支付股投资**：杠铃策略——Visa（护城河稳）和FISV（赔率高跌至个位数PE）；Circle关注AI支付未来。

<a id="基金与a股策略"></a>
#### **6.3 基金与A股策略**

**国内基金**：量化微盘股基金（如金元顺安元启）靠分散小票和风格赌注跑赢；主观基金（如张坤）周期性过强。

**A股红利**：韭菜红利驱动（资金出不去，炒概念小票）；类债券资产（水电）和量化基金更稳。

<a id="自媒体实操问题"></a>
#### **6.4 自媒体实操问题**

**起步专注**：初期勿发散赛道或想法，先像素复制一个增长中对象（如旅居YouTuber），赚到钱再拓展。

**平台选择**：欧美卖课用YouTube（长内容公域成交）或TikTok（短内容导直播），墙内注意资质限制。
