#  **金融时代投资逻辑与市场分析**

# **课程摘要**

本次直播主要围绕金融时代的投资逻辑与市场分析展开，首先回顾了之前对黄金、白银等贵金属的判断，并指出当前金银市场走势符合预期。接着，详细介绍了巴菲特在铁路时代、石油时代、消费时代的投资案例，并分析了金融时代股票的共同特点，特别是支付网络系统的网络效应。随后，重点讲解了美股中几大金融基础设施的股票，如Visa、Mastercard、美国运通等，并对比了中国A股市场中类似公司的现状与不足。此外，还讨论了交易所、评级机构、信用分等金融基础设施的商业模式与投资价值，并指出中国资本市场在金融基础设施方面的不足。最后，针对当前市场情况，提出了左侧交易与右侧交易的适用条件，并分享了个人对中概互联网公司、加密交易所等投资机会的看法。

#### **1.3 支付行业护城河验证**

互联网支付层（PayPal/Stripe/ApplePay）未颠覆底层网络，反成Visa/Mastercard分销渠道。区块链支付替代需经历三阶段演进：

1. 国际支付市场突破（跨境场景优先）
2. 消费场景网络效应构建（如谷歌生态接入）
3. 主流国家渗透（需克服现有支付便利性）

<a id="全球金融交易所投资价值"></a>
### **2 全球金融交易所投资价值**

<a id="核心交易所标的"></a>
#### **2.1 核心交易所标的**

1. **纳斯达克交易所（NDAQ）**：2008年低点\$4.5→2021年高点\$100，20倍涨幅。核心逻辑：无论科技公司表现如何，交易所作为”卖水人”持续受益
2. **洲际交易所（ICE）**：掌控油气定价权及美国房贷技术平台（覆盖贷款全流程数据管道）
3. **芝加哥期权交易所（CBOE）**：期权交易量激增反映Z世代投机需求增长（“年轻人翻身靠期权”心态）

<a id="区域交易所比较"></a>
#### **2.2 区域交易所比较**

1. **港交所（0388.HK）**：受益中概股回流+中国科技公司IPO（如蓝箭航天pre-IPO估值750亿），近期流动性改善因韩国投资者涌入炒作质谱、MiniMax等标的
2. **多伦多交易所（TMX）**：掌控全球50%矿业融资，随大宗商品周期走强
3. **新兴市场机会**：印度交易所具备确定性（伴随经济高增长及财富效应）

<a id="交易所护城河本质"></a>
#### **2.3 交易所护城河本质**

流动性聚集产生网络效应：优质资产选择单一交易所上市→吸引流动性→带动其他资产上市。币圈交易所缺陷在于：资产可在多平台交易削弱护城河；当前主要交易空气币，未绑定真实价值资产

<a id="金融信息服务平台"></a>
### **3 金融信息服务平台**

<a id="指数与评级机构"></a>
#### **3.1 指数与评级机构**

1. **标普全球（SPGI）**：1925年成立，百年品牌构建信任壁垒。标普500ETF管理规模带来持续收入
2. **穆迪（MCO）**：业务覆盖股票/债券/贷款评级，历史走势强于指数公司
3. **中国缺失对标**：中证/国证指数公司未上市；本土评级机构边缘化（政府掌握定价权）

<a id="信用分核心基础设施"></a>
#### **3.2 信用分核心基础设施**

**FICO（FICO）**：垄断美国信用评分市场（90%贷款决策采用其模型），1956年成立。核心壁垒：监管机构将其写入合规指引，银行不敢更换模型

1. 股价逻辑：信用扩张周期中受益，但当前估值仍达50倍PE（历史高位80倍）
2. 中国对标缺失：人行征信中心非市场化运作，且违约惩罚具无限责任特征

<a id="金融数据终端"></a>
#### **3.3 金融数据终端**

1. **汤森路透（TRI）**：金融事件响应速度最快（记者全球实时覆盖），近期因AI冲击担忧股价腰斩（\$287→\$117）
2. **彭博**：未上市，生态位相似但数据覆盖更广
3. **中国现状**：万得（Wind）仅覆盖A股为主，港股数据不全；Choice等平台未形成垄断

### **4 银行与投行领域**

<a id="中美银行股差异"></a>
#### **4.1 中美银行股差异**

1. **中国银行股估值逻辑**：政策工具属性导致破净常态化（需低于0.8倍PB）

2. **美股银行股风险**：高杠杆经营模式，金融危机中跌幅惨烈（如花旗2008年跌99%）

#### **4.2 投行投资前景**

当前估值已反映景气周期（摩根士丹利等涨幅巨大），高负债经营本质决定其易成危机导火索。历史教训：雷曼倒闭警示杠杆风险

<a id="投资策略实战解析"></a>
### **5 投资策略实战解析**

<a id="交易时机选择标准"></a>
#### **5.1 交易时机选择标准**

1. **左侧交易适用场景**：

1. 资产反身性弱（下跌不导致基本面恶化）
2. 绝对低估指标出现（市净率/股息率）
3. 股息率>3%时可分批建仓（如长江电力3.5%股息 vs 中国国债<2%）

2. **右侧交易适用场景**：

1. 强周期或高波动资产（如Robinhood）
2. 需等待底部横盘确认（参考Coinbase走势）

<a id="持仓管理原则"></a>
#### **5.2 持仓管理原则**

1. **长线持股卖出信号**：

1. 估值触及历史波动区间上限
2. 月线突破长期上升通道上轨
3. 连续两月加速上涨（非理性泡沫特征）

2. **案例示范**：

1. 纳斯达克交易所（NDAQ）：2021年突破年线通道上轨+连续两年加速，触发卖出信号
2. FICO：2023年PE达58倍（历史上限）+季度涨幅超20%，满足减仓条件

<a id="特殊资产估值框架"></a>
#### **5.3 特殊资产估值框架**

1. **房产投资逻辑**：

1. 非标资产特性：下跌缓慢（割肉盘驱动），上涨迅猛（情绪逆转跳涨）
2. 租金收益率对标无风险利率，左侧布局优于右侧追涨

2. **周期股股息陷阱**：需用多年平均分红计算真实股息率（避免单年异常值误导）

### **6 重点公司深度研判**

<a id="特斯拉tsla"></a>
#### **6.1 特斯拉（TSLA）**

1. **短期压力**：

1. 电动车业务遭遇中国品牌挤压
2. 政策透支需求（中国购置税减免取消影响300万辆/年需求）
3. 政治表态影响欧美市场（加拿大/欧洲政策风险）

2. **长期看点**：

1. FSD自动驾驶（潜在颠覆出租车市场）
2. 机器人业务（虽存在跳票可能）

<a id="台积电tsm"></a>
#### **6.2 台积电（TSM）**

1. **核心优势**：半导体代工绝对龙头（GPU/ASIC依赖其工艺）
2. **估值锚点**：

1. PEG=1为分水岭（当前PE=25倍对应25%增速，PEG=1）
2. 40倍PE为危险阈值（需业绩消化估值）

3. **地缘风险**：巴菲特因担忧台海局势低位抛售

<a id="加密货币关联机会"></a>
#### **6.3 加密货币关联机会**

1. **BTC底部信号**：次主流矿机关机价（参考蚂蚁S21关机价\$50,000）
2. **交易所突破点**：绑定真实资产（如SpaceX上市）而非当前空气币
3. **以太坊质疑**：基金会持续高位抛售+监管不友好（难以承接RWA资产）
